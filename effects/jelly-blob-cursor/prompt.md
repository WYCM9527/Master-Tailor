## 效果描述

系统光标被换成几团软软的圆球：最大的一团紧跟着鼠标，后面几团越来越小、拖得越来越远，像一串被牵着的果冻。鼠标停下时它们慢慢聚拢，靠近的球边缘会黏在一起融成一团；鼠标快速移动时又被拉成一条黏黏的尾巴。球的数量、大小、拖得多远、黏合的程度都可调，也可以选择保留系统光标。

## 实现提示

球层套一个 SVG 滤镜实现黏合：feGaussianBlur（stdDeviation 即黏合强度）→ feColorMatrix 把 alpha 做高对比（如 0 0 0 24 -12）→ feComposite atop 回填原色，模糊后相邻球的边缘就融为一体。每个球是绝对定位的圆形 div，用 requestAnimationFrame 做链式跟随：第一个球按迟滞系数追鼠标，后面的球追前一个球，序号越大迟滞略大、缩放略小。cursor: none 隐藏系统光标（可选）。

## 完成后请检查

- 球靠近时边缘确实融合成一团，分开时又是独立的圆，没有生硬的叠加边
- 快速移动时形成拖尾，停下后依次归位不抖动
- 系统开启「减少动态效果」时球直接跟在鼠标下、不拖尾不黏合
