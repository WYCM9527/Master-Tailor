## 效果描述

一段正文里有几个关键词，页面加载后像有人拿笔在纸上标注：荧光笔从词的左边一划到右边、涂满整个词的高度，颜色半透明地垫在文字下面；换成下划线就是一条微微弯的手绘线，方框、圆圈、删除线、方括号同理。每处标注都是「画出来」的——笔画从起点逐渐延伸到终点，而且会描两遍，两遍的抖动略有不同，所以有真人握笔的手感。画完停一会儿，墨迹淡去，再用新的随机抖动重画一遍。样式、颜色、粗细、画的速度、描几遍、间距、手抖程度都可调。

## 实现提示

段落文字里用【】包住的词替换成 `<mark>`（背景透明）。在段落容器下面垫一张等大的 SVG（`position: absolute; inset: 0; z-index: 0`，文字 z-index: 1）。用 `mark.getClientRects()` 拿到每个词在每一行的矩形（换行的词会有多个），按样式为每个矩形生成路径：下划线 / 删除线 / 方框边 / 方括号都是三次贝塞尔线段——起终点加随机偏移、两个控制点放在 1/3 和 2/3 处并加更大的偏移让线微弯；圆圈是 48 个采样点各自抖动后用二次贝塞尔经过相邻中点平滑连接；荧光笔是一条 stroke-width ≈ 文字高度、略带倾斜的粗线，opacity 0.75。描第二遍时反方向、重新随机。动画用 `stroke-dasharray = 路径长度` 配合 Web Animations API 把 `stroke-dashoffset` 从长度动到 0，各笔画按顺序设 delay，总时长按各矩形宽度比例分配。窗口尺寸变化时重画。

## 完成后请检查

- 笔画从一端逐渐画到另一端，多遍描摹时两遍轨迹略有不同
- 跨行的关键词每一行都有各自的标注；荧光笔垫在文字之下不遮字
- 系统开启「减少动态效果」时直接显示画好的标注，不循环
