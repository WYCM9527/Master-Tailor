## 效果描述

一张竖版图片卡片安静地摆着。鼠标移入的一瞬，一道斜向的亮光带从卡片右下角快速扫过整张卡到左上角，像有人拿着灯掠过一块玻璃面；鼠标移出时光带可以沿原路扫回，也可以直接消失。光带的颜色、亮度、宽度、倾斜角度和扫过的快慢都可调。

## 实现提示

卡片 overflow: hidden，内部叠一层 pointer-events: none 的 div 作光带：background-image 是「透明 → 光色（按亮度用 color-mix 调透明度）→ 透明」的斜向 linear-gradient（角度即光带角度，中段宽度用 calc(50% ± 宽度/2)），background-size 300% 300%，静止时 background-position 100% 100%，:hover 时过渡到 0% 0%，transition 时长即扫过时长；「移出时扫回」开关用 CSS 变量 0/1 乘到非悬停态的 transition-duration 上。缩略图演示可用定时器切换一个与 :hover 同效的类。

## 完成后请检查

- 光带是一条斜向亮带从一角扫到对角，扫完后卡片恢复干净，不留半截光
- 移出时按开关扫回或直接消失；快速反复移入移出不会卡在中间
- 系统开启「减少动态效果」时光带直接出现 / 消失不扫动
