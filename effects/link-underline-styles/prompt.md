## 效果描述

一列导航链接，悬停时出现各式各样的下划线动画，一个开关切换八种：一根线从左边划入、移开时向右缩走；两根线上下相向划入；主线划入并加粗、副线稍后跟上；文字自己向左滑出、同一份换色的副本从右滑入、底下划线同步划入；一根线从文字正中横穿、文字微微放大；一块色从底线长满整行再从上方收走、留下换了色的文字；一长一短两根线先后从下方浮起；一条手绘感的波浪线从左往右一笔画出。颜色、粗细、时长、字号都可调。

## 实现提示

每个链接 `position: relative`，用 `::before`（主线）和 `::after`（副线）做线条，默认 `top: 100%; height: 粗细; background: 线色`。划入类靠 `transform: scaleX(0 → 1)` 配合 `transform-origin` 切换（默认 `100% 50%`，悬停 `0 50%`，这样进出方向相反）。加粗用 `scale(1, 2)`；换位把文字包在 `<span>` 里 `translateX(−150%)`、副本从 `150%` 到 0，链接 `overflow: hidden`；中线把 `::before` 的 `top` 设 50%；色块盖过用关键帧：`scaleY(0.045 → 1)`（origin 底部）再 50% 处切 origin 到顶部 `scaleY(1 → 0.045)`；双线浮起用 `opacity` + `translateY(3px → 0)` 与不同 `transition-delay`；手绘描画用 SVG `<path pathLength="1">` 的 `stroke-dasharray: 1; stroke-dashoffset: 1 → 0` 过渡。过渡曲线用 `cubic-bezier(0.7, 0, 0.2, 1)` 一类快进慢出。

## 完成后请检查

- 八种样式在同一份文字上都成立，悬停进入与离开方向合理
- 线条粗细、颜色随参数变化；换位变体不出现文字重叠或溢出
- 系统开启「减少动态效果」时无过渡；没有鼠标时缩略图里轮流演示
