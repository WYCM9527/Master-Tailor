## 效果描述

一根两端圆头的进度条，里面是一段可以拖动的填充条，右端停着当前数值。拖着填充条往右走，条头顶到数值时把它挤进条内侧、换成填充上的颜色并跟着条头继续走；条头在中段是直角，一进入右侧圆头区域就逐渐弯起来，推到顶点时与轨道的内圆完全重合。数值每变一次，变化的那几位数字都带着模糊翻一页。点哪里就跳到哪里，也能用键盘微调。

## 实现提示

- 结构：轨道是 `overflow: hidden` 的胶囊（宽 {{width}}、高 {{height}}、圆角 = 高 / 2、底色 {{track}}），里面一条绝对定位的填充条（{{fill}}）和一个绝对定位的数值标签；轨道本身是 `role="slider"`、可聚焦。
- 填充条几何：宽 = 高 + 进度 × (轨道宽 − 高)——0% 时是一颗直径等于高的圆头，100% 到轨道尽头；左端圆角恒为高 / 2。条头（右端）圆角 r = t × 高 / 2，t = clamp((条右缘 − (轨道宽 − 高 / 2)) / (高 / 2), 0, 1)：没进右侧圆头区域时 r = 0 是直角，进入后线性弯起，到顶点 r = 高 / 2 与轨道内圆重合。条头上两道 2px 抓握线（间距 5px、高 30%），透明度 0.35 × (1 − t)。
- 数值标签：字号 = 高 × 0.36、粗体、等宽数字；默认停靠位 x = 轨道宽 − 内边距 − 标签宽（内边距 = 高 × 0.32），颜色 {{color}}。当条右缘 ≥ 停靠位 − 6px 时切到「内侧」：x = 条右缘 − 2 × 内边距 − 标签宽（多让一个内边距给抓握线），颜色换成 {{colorOnFill}}；标签只用 `transform: translateX` 移动，`transition: transform 0.28s cubic-bezier(0.2, 0.8, 0.2, 1)`（拖动中缩短到 0.12s 以免落到条头外面），单位文字 {{unit}} 略小并 0.7 透明度。
- 模糊翻页：数值按位渲染成等宽的 span，只替换发生变化的位，新节点带关键帧：从 `translateY(45%)`（数值减小时改为 −45%）、`filter: blur(6px)`、透明 0 到原位清晰，时长 {{flip}}、缓动 `cubic-bezier(0.2, 0.8, 0.2, 1)`；位数变化（如 99 → 100）时整组重建。
- 交互：pointerdown 时 `setPointerCapture`、按指针位置设值并关掉填充条的过渡（拖动跟手），pointerup 恢复 `width / border-radius 0.25s` 的过渡（点击跳转有缓动）；指针 x 映射为进度 = (x − 高 / 2) / (轨道宽 − 高)，让条头右缘领先指针半个圆头。键盘左右 ±1、Shift ±10、Home / End 到两端，同步 `aria-valuenow`。
- 初始进度 {{value}}；宽高都是 CSS 变量，几何在每次渲染时从元素当前尺寸读取，resize 重渲染。
- `prefers-reduced-motion` 下去掉翻页动画与过渡，数字直接换、位置直接跳。

## 完成后请检查

- 条头在中段是直角，进入右侧圆头区域后逐渐弯曲，拖到顶点时与轨道圆头严丝合缝、没有露出轨道底色的缺口
- 数值被顶到时切到条内侧并换色，之后跟着条头走；往回拖过接触点又回到右端停靠位
- 只有变化的那几位数字翻页，方向随数值增减；系统开启「减少动态效果」时数字直接切换
