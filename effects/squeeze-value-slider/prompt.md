## 效果描述

一根两端圆头的胶囊滑块：左端到滑条前一小段是填充条（渐变或纯色），前面立着一条细竖线滑条，右端停着当前数值。拖着滑条往右走，填充条跟着变长、逐渐露出更多渐变；快碰到数值时数值翻到滑条左侧、贴着它一起走。滑条在中段笔直，一进入圆头区域就逐渐弯起来、变高，推到顶点时正好是一段与轨道圆头同心的内圆弧。数值每变一次，变化的那几位数字带着模糊翻过去，没变的位保持清晰。点哪里就滑到哪里，也能用键盘微调。

## 实现提示

- 结构：轨道是 `overflow: hidden` 的胶囊（宽 {{width}}、高 H = {{height}}、圆角 = H / 2、底色 {{track}}），里面依次是填充条、一个铺满轨道的 SVG（只有一条 `<path>`）、数值标签；轨道本身 `role="slider"`、可聚焦。
- 位置用 0–1 的连续值 pos 表示（拖动时不按 1% 跳格），显示数值 = round(pos × 100)；初始进度 {{value}}。滑条顶点 x = 0.15H + pos × (宽 − 0.3H)，即顶点离两端最近 0.15H。
- 滑条几何：`stroke` = {{handle}}、`stroke-width` = {{thickness}}（写在 CSS 变量里，改粗细不用重算路径）、圆头线帽、无填充；下面的坐标都指线的中心线。进入右侧圆头区域的深度 t = clamp((顶点 x − (宽 − H / 2)) / (H / 2 − 0.15H), 0, 1)，左侧同理取镜像，再做 ease-out：t = 1 − (1 − t)²。半高 hh = 0.205H → 0.29H 按 t 线性（直线高 0.41H，满弧高 0.58H）；弓高 s = t × (0.35H − √(0.35H² − 0.29H²)) ≈ t × 0.154H；弦的 x = 顶点 x − s（左侧为 + s）。s < 0.05px 时画直线 `M x, cy−hh L x, cy+hh`；否则画圆弧 `M 弦x, cy−hh A rr rr 0 0 1 弦x, cy+hh`，rr = (hh² + s²) / (2s)，向左弯时 sweep 标志改 0。这样 t = 1 时 rr = 0.35H、圆心落在轨道圆头的圆心上，弧与内圆完全同心。
- 填充条：左端贴轨道、`border-radius: inherit`、高 100%，宽 = max(0, 滑条最左缘 − 0.16H)。填充颜色 {{fill}}：只有一个颜色时 `background-image: linear-gradient(c, c)`（纯色）；多个颜色时 `linear-gradient(90deg, c1, c2, …)` 均匀分布。渐变要按整根轨道的宽度铺：`background-repeat: no-repeat; background-size: 轨道宽 100%`（轨道宽由 JS 每次渲染写进 CSS 变量），这样填充条变长是逐渐把渐变露出来，而不是把渐变拉伸。
- 数值标签：字号 0.34H、字重 600、等宽数字，颜色 {{color}}，数字与单位 {{unit}} 之间 0.25em 间距，只用 `transform: translateX` 定位，`transition: transform 0.3s cubic-bezier(0.2, 0.8, 0.2, 1)`（拖动中缩到 0.16s）。停靠位：右缘离轨道右端 0.3H。当顶点 x + 0.3H ≥ 停靠位的左缘时翻到滑条左侧：右缘 = 顶点 x − 0.4H，之后每帧跟着顶点走；条件不成立就回停靠位。
- 模糊翻页：每一位是一个 `inline-grid` 格子，里面新旧两个 span 叠在同一格（`grid-area: 1 / 1`）。某位变化时用 Web Animations API：新字从 `translateY(55%)`、`blur(0.2em)`、透明 0 滚到原位清晰，旧字从原位滚到 `translateY(−55%)`、`blur(0.2em)`、透明 0（数值减小时两者方向反过来），时长 {{flip}}、缓动 `cubic-bezier(0.2, 0.8, 0.2, 1)`。若该位的翻页还在进行中，只改新字的文字、不重启动画——连续拖动时这一位始终是模糊的，停下后最后一次翻页把它落清楚。位数变化（99 → 100）时整组重建，不做动画。
- 交互：`pointerdown` 时 `setPointerCapture`，把指针 x 换算成 pos = (x − 0.15H) / (宽 − 0.3H) 并用 260ms `1 − (1 − k)³` 的 rAF 缓动滑过去；`pointermove` 拖动时取消缓动、直接写 pos。键盘左右 ±1、Shift ±10、Home / End 到两端，同样带缓动；数值变化时同步 `aria-valuenow`。
- 宽高都是 CSS 变量，几何在每次渲染时从元素当前尺寸读取；用 `ResizeObserver` 同时观察轨道和数值标签，尺寸一变（改了变量、字体加载后标签变宽）立刻重渲染，另外 `document.fonts.ready` 后再渲染一次，不要等到下一次交互。
- `prefers-reduced-motion` 下不做翻页动画、标签不做过渡、点击直接跳到目标位置。

## 完成后请检查

- 滑条中段笔直，进入圆头区域后逐渐弯曲且变高，拖到顶点时弧与轨道圆头同心、两端离轨道边缘留有均匀间隙
- 填充条停在滑条前一小段；多色时渐变铺满整根轨道、随填充变长逐渐露出，单色时是纯色
- 数值默认停在右端，滑条逼近时翻到滑条左侧并贴着它走，往回拖离开后又回到右端
- 只有变化的那几位数字翻页且带模糊，方向随数值增减；连续拖动时那一位持续模糊、停下后落清楚；系统开启「减少动态效果」时数字直接切换
