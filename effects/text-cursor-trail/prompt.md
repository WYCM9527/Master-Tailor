## 效果描述

鼠标在页面里移动时，身后拖出一小串符号（默认一个原子 emoji，也可以换成任意字或词）：每隔固定距离放一个，符号顺着移动方向倾斜排列，最多保留几个；停下不动时，尾巴上的符号从最远端一个接一个缩小淡出收走，直到全部消失。在位的符号还会轻轻晃动。符号、间距、数量、是否随方向旋转、收走时长与间隔、颜色字号见参数。

## 实现提示

- 维护一个「在场符号」数组（最老的在前）。pointermove 时算与上一次落点的距离，每满一个间距（{{spacing}}）就沿线段插值放一个符号；方向角 `atan2(dy, dx)`，超过 ±90° 的加减 180°，文字不会倒立。数组超过上限（{{maxPoints}} 个）就把最老的收走。
- 收走机制：记录最近一次移动时间，每隔收走间隔（{{removalInterval}}）用 `setInterval` 检查一次，发现「停手超过 100ms 且数组非空」就把最老的一个收走——所以停下来后尾巴是逐个收起，而不是同时消失。
- 符号元素：`transform: translate(-50%, -50%) rotate(方向角)` 负责居中与方向；「在位轻晃」用独立的 `translate` / `rotate` 属性做 2s 往返（alternate）动画，±5px / ±5°，与 transform 互不干扰。进场 0.2s 淡入。
- 收走：加一个类，把晃动动画暂停，`opacity: 0; scale: 0` 过渡「收走时长」（{{exitDuration}}），过渡完删掉 DOM。

## 技术要求补充

- 纯 DOM + CSS 动画，不需要 canvas。
- 隐藏系统光标（`cursor: none`）让符号串成为唯一的指针反馈。
- 系统开启「减少动态效果」时不撒符号。

## 完成后请检查

- 符号沿移动方向倾斜排列（斜着划就是斜的），间距均匀
- 停手后从最远端开始逐个缩小消失，不是一起消失
- 最多同时存在设定的个数，快速划动时也不会堆积
