## 效果描述

鼠标在空白区域里移动时，身后每隔一小段距离就撒下一个小字或符号：出生时轻轻弹大一下，带着随机的倾斜角落在轨迹上，然后按选定的方式退场——缩小淡出、上浮淡出或原地淡出。移动越快撒得越密（间距是按路程算的，不是按时间），同屏数量有上限，最早的先消失。可以配置多个词轮流撒。

## 实现提示

监听 pointermove，把当前点与上一次撒点之间的距离按「撒落间距」等分，在每个等分点各撒一个绝对定位 span（left/top = 坐标，用 translate(-50%,-50%) 居中）；每个 span 一条 keyframes：0% 透明缩小 → 15% 放大到 1.15 → 35% 回到 1 → 100% 透明并走向消失方式对应的终态（缩小 / 上浮 / 原地），旋转角用 CSS 变量传入，时长即存活时间；animationend 后移除节点，超出同屏上限时先移除最早的。

## 完成后请检查

- 快速划过时撒下的字沿轨迹均匀分布，没有大段空缺；慢速时也能持续撒
- 每个字都会在存活时间后消失，页面上不会无限堆积节点
- 系统开启「减少动态效果」时不撒字
