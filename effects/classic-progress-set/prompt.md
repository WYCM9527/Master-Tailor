## 效果描述

白色卡片上方是标题、百分比和重播按钮，下面排着一组老牌进度条：斜纹往前流动的、白框里一串小方块从左跑到右的、按整格点亮且下一格一闪一闪的、带玻璃高光的胶囊、前后交替扫过的不定进度，以及隔一阵扫过一道白光的。打开时能显示具体进度的几条一起走到设定进度，中途顿一顿；点重播再走一遍。选定单一样式时只留那一条。

## 实现提示

- 卡片 min(600px, 92vw)、白底、圆角 18px、内边距 24px 28px 28px；头部是 16px 粗体「{{label}}」、14px 灰色百分比和 IconPark refresh 重播按钮。每行左侧 76px 宽的 13px 灰色样式名，右侧进度条高 {{height}}、圆角 {{radius}}、轨道 {{track}}，行距 16px。{{style}} 为单一样式时只留那一行、隐藏样式名。
- 斜纹：{{color}} 填充叠 45° 白色 22% 斜纹（20px 一格），1 秒向前流一格。
- 跑马灯：白底加 1px 内描边，三块宽为 0.7 倍高度、间隔 2px、上亮下暗的小方块，2.2 秒从左外跑到右外。
- 分格：白底内描边、内缩为高度的 20%（限 1–3px，跑马灯方块同），每格 10px 加 2px 间隔，按整格点亮；下一格 0.8 秒一闪，满格不闪。
- 光泽胶囊：全圆角加内阴影，填充上半截白色高光，下层 −45° 主色与浅色相间斜纹（各 8px），1.6 秒流过一个周期。
- 不定进度：2.1 秒一轮，第一段从 −35% 扫到 100%，第二段晚 1.15 秒、更快地从 −200% 扫到 107%。
- 光带：填充上一道 40% 宽的白色渐变，2 秒一轮扫过（后 30% 停顿）。
- 以上时长都除以 {{speed}}。打开 0.3 秒后，用 1.8 秒 / {{speed}} 从 0 走到 {{value}}：先到 42%，停一下，到 82%，再停一下，最后缓入到位。

## 技术要求补充

- 能显示进度的条用 role="progressbar" 并更新 aria-valuenow，跑马灯和不定进度不带数值；重播走完用 aria-live 播报
- 系统开启「减少动态效果」时所有流动、闪烁停住，跑马灯和不定进度停在中段，重播直接到位

## 完成后请检查

- 斜纹和光泽胶囊流动时没有接缝跳动
- 分格进度不出现半格，进度改变时按整格增减
- 单选跑马灯或不定进度时，头部百分比换成「请稍候…」
