## 效果描述

页面顶部左右各一颗白色「气泡」：左边是 logo 胶囊，右边是圆形汉堡按钮。点一下按钮，两条线交叉成 ×，同时一排大号药丸从画面中央像气泡一样交错弹出——每颗药丸都很大（约 160px 高、大字号），交替向左右倾斜几度，弹出时带弹簧过冲，里面的文字比药丸稍晚一点从下方滑入。鼠标悬停哪颗药丸，它就放大一点并染成自己专属的颜色（默认蓝、绿、橙、红、紫），文字变白。再点按钮，药丸快速缩回消失。菜单项、颜色、倾角、弹出时长与交错间隔见参数。

## 实现提示

- 布局：药丸列表是 `flex-wrap`，每项占 1/3 宽（3 列）；5 项时第 4 项 `margin-left: calc(100%/6)` 让第二行居中，4 项时第 4 项 `margin-left: calc(100%/3)`。药丸 `min-height: 160px; border-radius: 999px; font-size: clamp(1.5rem, 4vw, 4rem)`，白底带柔影。
- 倾斜：给每颗药丸一个 CSS 变量 `--rot`，方向按「首尾向左、中间向右」交替；所有 transform 都写成 `rotate(var(--rot)) scale(...)`，悬停 `scale(1.06)`、按下 `scale(0.94)`。
- 弹出：初始 `scale(0)`，打开时切换到 `scale(1)`，过渡用带过冲的 `cubic-bezier(0.34, 1.56, 0.64, 1)`（模拟 back.out）；每颗药丸的 `transition-delay = 序号 × 交错间隔 ± 50ms 随机`。文字 span 初始 `translateY(24px); opacity: 0`，用平滑的 `cubic-bezier(0.22, 1, 0.36, 1)` 同步滑入。
- 悬停态要把 `transition-delay` 清成 0，否则交错延迟会让悬停变色慢半拍。
- 关闭：加一个 closing 类把所有过渡改成 0.2s ease-in、无延迟，缩回后再隐藏容器。汉堡两条线：开启时分别 `translateY(±4px) rotate(±45deg)`。

## 技术要求补充

- 纯 CSS 过渡 + 少量 JS 切类，不需要动画库。
- 容器先 `display: flex` 再在下一帧加开启类，否则第一次打开没有过渡。
- 系统开启「减少动态效果」时去掉所有过渡，直接出现 / 消失。

## 完成后请检查

- 药丸很大、交替倾斜、有弹簧过冲地交错弹出，文字比药丸略晚滑入
- 悬停立即染色放大，不同药丸颜色不同；按下微缩
- 关闭时快速缩回，汉堡线开合成 ×
