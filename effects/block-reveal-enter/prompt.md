## 效果描述

页面上的标题、一段正文、一张图和一颗按钮，一开始什么都看不见。然后一块蓝色的色块从标题的左边长出来、向右铺满整个标题的范围，铺满的瞬间标题出现在色块后面，色块紧接着从左边开始向右收走、露出标题；正文、图片、按钮各晚一点依次经历同样的「盖住—揭开」。也可以让色块收走后留一条细边当装饰。方向、留边比例、错开时间、时长、颜色都可调，点击可重放。

## 实现提示

每个内容元素外包一层 `position: relative` 的容器，内容默认 `visibility: hidden`，容器里放一个 `position: absolute; inset: 0` 的色块。用 Web Animations API 串两段：第一段 `transform-origin` 设在起始侧，`scaleX(0 → 1)`（纵向用 scaleY）；结束后把内容设为可见、把 origin 换到另一侧，第二段 `scaleX(1 → 留边比例/100)`。缓动用 `cubic-bezier(0.86, 0, 0.07, 1)`（ease-in-out-quint 手感），两段各用设定时长，第 i 个元素延迟 `i × 错开`。方向表：lr 起点左 / 终点右，rl 反之，tb 与 bt 用 scaleY 和上下 origin。

## 完成后请检查

- 色块先长满再收走，内容恰在色块盖满时出现，不会提前露出
- 四个元素按序错开；留边设置后收走时保留一条色边
- 系统开启「减少动态效果」时直接显示内容
