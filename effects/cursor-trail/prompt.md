## 效果描述
鼠标在页面上移动时，身后跟着一条发光的丝带：头部最粗最亮，越到尾部越细越透明，最终消散，鼠标头部还有一个小亮点。丝带不是僵硬地贴着鼠标，而是带着柔顺度稍稍滞后地跟随，快速甩动时会像绸带一样划出弧线。开启发光叠加后，丝带交叠的地方更亮，像光在流动。

## 实现提示
- 全屏 canvas（`position: fixed; inset: 0; pointer-events: none`，分辨率跟随 devicePixelRatio、上限 2），body 光标设为 crosshair；屏幕正中一行提示字「移动鼠标，拖出一条流光」（#6d7285、13px、字距 0.1em、不可选中）。
- 维护 {{trailLen}} 个轨迹点，初始全部放在屏幕中心；mousemove 只更新目标点，不直接写入点列。每帧做链式追随：第 0 点 `p0 += (目标 − p0) × {{smooth}}`，第 n 点 `pn += (p(n−1) − pn) × {{smooth}}`——同一个系数既决定头部的滞后感也决定尾巴的甩动，快速画圈时自然形成弧线，鼠标停下后整条尾巴逐点收拢到头部。
- 每帧先 `clearRect` 整屏（不留残影），再沿点列画由粗到细、由实到透的线段：第 i 段（i 从 1 起）取 `t = 1 − i / 点数`，颜色 = 流光颜色的 rgba，alpha = `t × 0.9`；`lineWidth = max(0.5, {{lineWidth}} × t)`；`lineCap: round`；每段单独 `beginPath / moveTo / lineTo / stroke`，这样才能逐段变细变淡。
- 头部再补一颗实心圆点，半径 `{{lineWidth}} × 0.7`，用不透明的流光颜色填充。
- 「发光叠加」开启时（当前 {{glow}}）在画线前把 `globalCompositeOperation` 设为 `lighter`（加色混合，交叠处更亮），关闭时用 `source-over`；头部圆点也在同一混合模式下画。
- 颜色每帧从 CSS 变量读取并转 rgb，方便实时改色；系统开启「减少动态效果」时不跑 rAF 循环，只在 mousemove 时清屏并画一颗同样半径的跟随光点。

## 完成后请检查
- 移动鼠标能拖出一条头粗尾细、渐隐的光带，快速画圈时是流畅的弧线不是折线
- 颜色、长度、宽度与柔顺度符合参数；鼠标停下后丝带缓缓收拢到光点
- canvas 层不拦截任何点击（pointer-events: none）；系统开启「减少动态效果」时只显示跟随光点、无拖尾
