## 效果描述

一页内容卡片的底部有个「查看详情」按钮。点它，一块顶部圆角、带小抓手条的面板从底部稳稳升起，占住画面下半部；背后的页面同时缩小一圈、轻轻压暗、四角变圆，像被放到了下一层。抓住抓手条往下拖一段、点右上角关闭、点遮罩或按 Esc，面板落回底部，背后页面亮回来恢复原大——关闭是打开的严格倒放。手感与 iPhone 的系统弹层一致。

## 技术要求补充

- 用同文档 View Transitions（document.startViewTransition）实现：面板挂自己的 view-transition-name，从底部升起/落下用方向化动画；背后页面的缩小与复原写成状态类的终态样式，让浏览器对前后快照自动补间
- 弹层打开时背后内容必须不可交互（inert 或等价手段），焦点移入弹层标题；关闭后焦点还给触发按钮
- 浏览器没有该 API 时降级为 CSS 类动画（面板与遮罩播同一套动画、背后页走过渡），视觉一致；开启「减少动态效果」时一律瞬间开合
- 弹层带 role="dialog" 与 aria-modal="true"

## 实现提示

弹层层（遮罩 + 面板）与内容页不互斥：内容页一直可见，弹层 hidden 切换。面板静态命名 view-transition-name: sheet（隐藏时不参与快照，不会重名），升降 keyframes 只动 translateY；背后页在转场瞬间临时挂名 page，缩小终态写在 .sheet-open 类里（scale + brightness + border-radius），快照补间自动完成。抓手下拉用 pointerdown/up 差值判断，超过约 70px 触发关闭。无 API 回退：面板 keyframes 原样加类播放，遮罩配一对淡入淡出。

## 完成后请检查

- 打开与关闭是同一段动画的正放与倒放；背后页面的缩小、压暗、圆角与面板升起同步进行
- 弹层打开时背后内容点不到、Tab 也走不进去；关闭后焦点回到触发按钮
- 不支持视图过渡的浏览器里开合依然顺滑；开启「减少动态效果」后为瞬间开合
