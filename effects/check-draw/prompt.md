## 效果描述

一列待办事项，每项前面一个圆角描边方框。点某一项，方框先被蓝色从中心弹性地填满（略微过冲），紧接着一个白色对勾从左下往右上一笔描画出来，同时方框四周向外迸出八粒蓝色小点并消散；这一项的文字上划过一道横线并变淡。再点一次取消：填充收回、对勾消失、划线退回。悬停时方框描边变蓝，按下时轻微缩小。颜色、方框大小、时长、小点数量都可调。

## 实现提示

用真实的 `<input type="checkbox">`（视觉隐藏）包在 `<label>` 里，样式全部靠 `input:checked ~ .box` 兄弟选择器驱动，键盘与无障碍天然可用。方框用 `box-shadow: inset 0 0 0 2px` 做描边；内部三样东西：填充层 `.fill`（强调色，`scale(0 → 1)`，曲线 `cubic-bezier(0.34, 1.56, 0.64, 1)`）；一个 SVG 对勾 `<path d="M5.5 12.5l4 4 9-9" pathLength="1">`，`stroke-dasharray: 1; stroke-dashoffset: 1 → 0`，延迟 30% 时长再开始描画；N 个小点 `.spark` 用 `--a` 角度各自 `rotate(a) translateX(...)`，选中时播一段 `translateX(0.5 → 1.1 倍框宽)` 并淡出缩小的关键帧。文字的 `::after` 做划线 `scaleX(0 → 1)`（origin 左），选中时 opacity 0.45。
