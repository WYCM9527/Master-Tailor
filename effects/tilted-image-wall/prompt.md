## 效果描述

整个背景是一面巨大的图片网格：六列圆角图片整齐排列，但整面墙在三维空间里被放倒——像铺在桌面上，从上方 55° 俯视，再在桌面上转了 45°，于是格子呈菱形网格斜着铺满屏幕、远处的略小。每一列都在缓缓滚动，相邻列方向相反，图片像传送带一样无穷循环。整面墙压暗一层，前面浮着标题。图片、列数、两个角度、速度、间距、压暗程度都可调。

## 实现提示

全屏舞台 `perspective: 1200px`；里面一块 200vmax × 200vmax 的正方形墙居中，`transform: translate(-50%, -50%) rotateX(俯视角) rotateZ(旋转角)`，墙内用 CSS Grid 分成 N 列。每列 `overflow: hidden`，里面一条 flex 纵向的图片轨道，轨道里把同一组图片连续放两遍；关键帧 `translateY(0 → calc(-50% − 间距/2))`，线性无限循环——正好滚过一遍序列，首尾无缝。偶数列 `animation-direction: reverse`，各列再给不同的负 `animation-delay` 错开起点，每列从图片序列的不同位置开始取图避免同图并排。上面盖一层半透明黑压暗，标题 z-index 最高。

## 完成后请检查

- 墙铺满屏幕四角无露边；菱形透视感明显、远处略小
- 各列滚动无缝、相邻列方向相反，图片不重复并排
- 页面在后台时暂停；系统开启「减少动态效果」时图墙静止
