## 效果描述

一行粗体大标题「形状 ▭ 会变」，中间那个「▭」不是字，是一个与字同高的小图窗：它的宽度在一个字宽到四五个字宽之间来回变化，圆角也跟着从方形变成胶囊、变成一角圆一角方的叶子形，像句子里嵌着一块会呼吸的橡皮泥，前后文字随之被推开、合拢。窗里是一串风景照排成一行不停向左滚过，无缝循环。鼠标悬停在窗上时变形与滚动都暂停。文字、图片、变形周期、滚动速度、字号都可调。

## 实现提示

标题用 `display: flex; align-items: center` 排成一行：前半句、图窗、后半句。图窗 `height: 1em; overflow: hidden`，用一段 `alternate` 往返的无限关键帧同时改 `width` 与 `border-radius`（如 3.2em / 0.5em → 1.6em / 50% → 4.5em / 0.1em → 2.4em / 上圆下方 → 1em / 对角圆 → 3.8em / 叶形），周期为参数，`ease-in-out`。窗内一个 `display: flex` 的轨道放两遍图片（每张 `height: 100%; aspect-ratio: 4/3`），`animation: translateX(0 → −50%)` 线性无限，第二遍图片刚好接上第一遍。悬停时两段动画 `animation-play-state: paused`。宽度变化会改变布局，所以前后文字自然被推开。

## 完成后请检查

- 图窗宽度与圆角连续变形、前后文字随之移动；窗内图片无缝滚动
- 悬停暂停、移开继续；改字号后窗高度随字高
- 系统开启「减少动态效果」时窗不变形、图片不滚
