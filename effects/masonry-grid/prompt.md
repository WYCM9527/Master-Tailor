## 效果描述

一墙高矮不一的图片卡按瀑布流排好（每块放进当前最矮的一列），页面打开时它们从画面外（默认下方）一张接一张飞进各自的位置，飞的过程中由模糊到清晰、由透明到实；落定后鼠标悬停哪张，它就轻微缩小一点。飞入方向可选上下左右、从中心散开或四面随机；可选悬停染色。图片、列数、时长、错开、模糊、缩放见参数。

## 实现提示

- 布局：容器宽度均分成 N 列（列间距 16px），第 i 块砖的高度按一组预设的高矮序列取，放进当前累计高度最小的那一列，记下 `(x, y, w, h)`；容器高度取最高列。砖块全部绝对定位，位置写进 `--x/--y` 再 `transform: translate(var(--x), var(--y)) scale(var(--s))`。
- 进场分两帧：第一帧关掉过渡，把每块砖摆到起点（下方 = 视口底 + 200px，上方 = −200px，左右同理，中心 = 容器中央）并加 `opacity: 0`、可选 `filter: blur(10px)`，强制回流；第二帧恢复过渡（`时长 × cubic-bezier(0.22, 1, 0.36, 1)`，第 i 块延迟 `i × 错开`），把位置改成目标、去掉透明与模糊。
- 落定后给砖块换成只针对 transform 的 0.3s 短过渡，悬停设 `--s = 缩放值`，离开设回 1；染色是一层随机色相的叠层悬停淡入到 0.3。
- 窗口变化时重算布局并直接改 `--x/--y`，砖块会平滑滑到新位置。

## 技术要求补充

- 纯 CSS transition + JS 算位置，无需动画库；图片 `object-fit: cover`。
- 系统开启「减少动态效果」时直接呈现，不飞入、不模糊。

## 完成后请检查

- 砖块高矮参差、列高均衡，是瀑布流不是等高网格
- 飞入有先后错开，且由模糊到清晰
- 悬停缩放平滑；切换飞入方向后起点随之改变
