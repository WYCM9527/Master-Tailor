## 效果描述

一条深色的胶囊形轨道里并排着四个选项：日、周、月、年。被选中的那一项背后垫着一颗白色胶囊，文字变成深色、前面亮起一个小圆点。点另一项时，白胶囊在轨道里滑过去，滑动途中横向被拉长、上下略压扁，到位时轻轻回弹恢复；原来那项的文字褪回灰色、圆点缩没，新的一项文字变深、圆点弹出。胶囊宽度自动匹配每个选项的宽度。颜色、时长、字号都可调。

## 实现提示

用真实的 `<input type="radio">`（视觉隐藏）包在 `<label>` 里，`role="radiogroup"`，键盘方向键天然可用。轨道 `position: relative; display: inline-flex; padding: 5px`；胶囊是一个绝对定位的元素（`top/bottom: 5px`），JS 在选中变化时把目标 label 的 `offsetLeft` 写进 `--x`、`offsetWidth` 写进 `width`，`transition: transform, width` 用 `cubic-bezier(0.3, 1.4, 0.4, 1)` 带回弹；切换瞬间给轨道加临时类，胶囊播关键帧 `40% { scale: 1.12 0.86 }` 再复原（独立的 `scale` 属性不会覆盖 translate）。选项文字 `z-index: 1` 压在胶囊上，选中时颜色过渡为深色；小圆点 `scale(0 → 1)` 用 `cubic-bezier(0.34, 1.56, 0.64, 1)`。窗口尺寸变化时重算胶囊位置。

## 完成后请检查

- 胶囊滑到选中项并匹配其宽度，滑动中拉长回弹；文字与圆点同步切换
- 键盘方向键可切换、有可见焦点；点文字任何位置都可选中
- 系统开启「减少动态效果」时直接跳到位；没人点时缩略图里轮流选中
