## 效果描述

一页图块排成网格。点任意一块，整个详情页就以那一块的位置为原点长出来——从很小的一点迅速舒展到占满全屏，越靠近点击处的内容越早出现，生长感由起始缩放决定。底下的网格页全程纹丝不动地垫着。返回或按 Esc 时严格反向：详情页缩回你当初点击的那个位置，消失在原点。点不同的图块，生长原点会跟着换。

## 技术要求补充

- 用同文档 View Transitions（document.startViewTransition）实现；点击时把被点图块的中心坐标写进 CSS 变量作为生长原点，每次点击都要更新
- 垫底的一页在整个转场中保持完全静止（不淡出、不位移），生长的一页在上层
- 浏览器没有该 API 时降级为 CSS 类动画（同一套动画加在真实页面上，原点坐标换算为相对容器），视觉一致；开启「减少动态效果」时一律瞬间切换
- 如果要在多页应用（两个独立 HTML）之间做同款转场：两页同源，各自声明 @view-transition { navigation: auto }（Chrome 126+ / Safari 18.2+，Firefox 暂不支持，需接受直接切换降级）

## 实现提示

两个「页面」是同文档里互斥显示的两块区域（hidden 切换）。转场期间给离场页与进场页都挂 view-transition-name: page；前进时 new 快照设 transform-origin 为点击坐标（快照坐标系是视口），keyframes 从 scale(起始缩放) 长到 1 并在前 30% 完成淡入；old 快照用一条 opacity 恒为 1 的「保持不动」动画覆盖默认交叉淡化。返回时把同一原点用在 old 快照上反向缩回，并用 z-index 提到上层。回退路径的 transform-origin 要用相对容器的坐标（视口坐标减容器偏移）。

## 完成后请检查

- 点不同图块，生长原点分别对准各自的位置；返回时缩回的终点就是当初的起点
- 垫底页全程静止，没有闪动或淡化
- 不支持视图过渡的浏览器里生长效果依然成立；开启「减少动态效果」后为瞬间切换
