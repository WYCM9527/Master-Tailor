## 效果描述

一条可以往下滚的长页，每一节是一张满幅大图。往下滚，当前大图先钉在原地不动，配套的标题和文字从下方浮上来慢慢显形；滚过临界点，下一节的大图从底部整幅顶上来，把上一张干脆地接走，一节接一节像接力棒交接。回滚时全程可逆。每节钉住的时间由每节滚动行程决定。旧一些的浏览器里文字不做浮现，但大图接力照常成立。

## 技术要求补充

- 文案浮现用 CSS 滚动驱动动画（animation-timeline: view()），必须整段包在 @supports (animation-timeline: view()) 里做渐进增强；「完全可见」要写成默认样式，不支持的浏览器（含 Firefox 稳定版）直接展示终态
- 大图的钉住与接力只用 position: sticky 完成，不写滚动监听 JS，任何浏览器都成立
- 滚动发生在效果自己的容器里（overscroll-behavior: contain），不得牵动页面其他部分；容器可聚焦，方向键能滚
- 图片满幅裁切展示，不得拉伸变形；开启「减少动态效果」时文案保持常显、不做浮现

## 实现提示

容器设 container-type: size 后，用 cqh 以容器高度为基准布尺寸：每节 height = 行程% × 1cqh，节内大图 position: sticky; top: 0; height: 100cqh，于是滚动时大图钉住、下一节自然从底部盖上来。文案放在流内、用负 margin 压到大图下沿，配 animation-timeline: view() + animation-range: entry 0% entry 80%，让透明度与上浮跟随自身入场进度。自动演示（如需）用 requestAnimationFrame 递增容器 scrollTop 往返，用户一操作立即停。

## 完成后请检查

- 大图接力的边界干脆：上一张全程钉住不位移，下一张整幅推上来盖过它
- 把浏览器换成不支持滚动驱动动画的（或用 Firefox）：文字常显、无消失或闪烁，接力不受影响
- 滚动只发生在效果容器内，页面本身不被牵动；回滚方向一切可逆
