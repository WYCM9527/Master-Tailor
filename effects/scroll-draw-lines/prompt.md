## 效果描述

一屏画面：中央一句标题，背景是五条颜色不同的细曲线的「轨道」——但一开始一条也看不见。往下滚动，画面本身定住不动，滚动量变成了画笔：五条线从画面左边出发，随着你滚动一点点向右描出来，在画面中央拢成紧紧的一束、再向右重新散开；越靠下的线开始得越晚一点。滚到底时五条线完整画完，标题在此过程中渐渐淡去。回滚则线条倒着收回。颜色、散开程度、线宽都可调。

## 实现提示

一个 320vh 高的滚动轨道，里面放一个 `position: sticky; top: 0; height: 100vh` 的舞台，滚动时舞台留在原地。舞台内一张 `viewBox 0 0 1440 600`、`preserveAspectRatio="xMidYMid slice"` 的 SVG，按颜色数量生成路径：第 i 条的起点、中点、终点 y 由它在 −1..1 的位置 k 决定（起点 `300 + 220k`、中点 `300 + 40k`、终点 `300 + 200k`），用三次贝塞尔 + S 命令连成「散—拢—散」的形状。每条路径 `stroke-dasharray = 总长`、初始 `stroke-dashoffset = 总长`（完全不显示）；监听滚动，进度 `k = scrollTop / 最大滚动量`，第 i 条 `dashoffset = 总长 × (1 − clamp((k − 0.06i) / (1 − 0.12i)))`。线加 `filter: drop-shadow(0 0 6px 同色)` 发光；标题 opacity = `1 − 1.6k`。

## 完成后请检查

- 未滚动时一条线也不显示；滚到底时全部画完、回滚时收回
- 线条从左向右生长、在中央拢成一束；各线开始时间略有先后
- 画面在滚动中保持定住；系统开启「减少动态效果」时不自动滚动
