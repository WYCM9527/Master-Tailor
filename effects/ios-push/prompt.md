## 效果描述

一列可点的条目排成手机设置页的样子。点进任意一条，新页面从右缘整页推入，旧页面同时向左让位一小段并轻轻压暗，新页左缘带一道细细的投影，交代出新页叠在旧页上方的层次。返回时严格反向：新页退回右侧，旧页亮回来滑回原位。按 Esc 或从左缘向右滑也能返回，手感与 iPhone 的系统页面切换一致。

## 技术要求补充

- 用同文档 View Transitions（document.startViewTransition）实现：切页前在 html 上标记方向（前进/返回），CSS 按方向选动画，保证返回是前进的严格反向
- 旧页的让位与压暗、新页的推入要同时同曲线进行；投影跟随处于上层的那一页
- 浏览器没有该 API 时降级为 CSS 类动画（两页短暂同框播同一套动画），视觉一致；开启「减少动态效果」时一律瞬间切换
- 如果要在多页应用（两个独立 HTML）之间做同款转场：两页同源，各自声明 @view-transition { navigation: auto }（Chrome 126+ / Safari 18.2+，Firefox 暂不支持，需接受直接切换降级）

## 实现提示

两个「页面」是同文档里互斥显示的两块区域（hidden 切换）。转场期间给离场页与进场页都挂 view-transition-name: page，得到 old/new 两张快照；前进时 new 从右缘平移入场、old 平移让位幅度并按压暗程度降低亮度（filter: brightness），投影用 box-shadow 画在上层快照左缘。无 API 回退：同一套 keyframes 以类名加在真实页面元素上。左缘右滑返回用 pointerdown/up 判断起点在容器左缘约 32px 内、右移超过阈值即触发。

## 完成后请检查

- 前进与返回是同一段动画的正放与倒放，旧页让位的距离和压暗程度按参数生效
- 转场进行中连续点击不会错乱（进行中的导航应被忽略）
- 不支持视图过渡的浏览器里推屏依然成立；开启「减少动态效果」后为瞬间切换
