## 效果描述

几张卡片排成整齐的网格安静地展示着，每隔一会儿其中一张绕自己的中轴翻个面，背面是另一张图。翻的顺序可以是一个接一个、沿对角线一波一波，或者随机；翻过的卡片下次再翻回来展示下一张，于是整面网格的图片在不知不觉中全部换过一遍。不需要任何操作，永不停歇。

## 实现提示

- 结构：一个 CSS Grid，{{cols}} 列 × {{rows}} 行，`gap: {{gap}}`；宽度 = min(86vmin × 列数 / max(列数, 行数 × 0.75), 94vw)，保证宽高都不超过画面短边的 86%。每格 `perspective: 900px`、4:3；格内一张双面卡 `transform-style: preserve-3d`，正反两面 `position: absolute; inset: 0; backface-visibility: hidden`，背面预先转 180°（左右翻用 rotateY，上下翻用 rotateX，{{axis}} 决定）。
- 翻面：卡片 `transform: rotateY(var(--turn))`，`transition: transform {{flipDuration}} cubic-bezier(0.4, 0, 0.2, 1)`。每次翻面先把「即将朝上的那一面」的图换成下一张（全局游标按图片列表循环），再把角度累加 180° 写进变量——只增不回绕，每次过渡永远只转半圈，也不会倒着转回去。
- 顺序（每 {{interval}} 翻一次，{{order}}）：逐个 = 行优先循环；对角波次 = 行号 + 列号相同的格子一起翻，波次按对角线序号循环；随机 = 每轮生成一个不重复的乱序，翻完一轮再重新打乱。
- 初始化：正面按序号取图，背面先放任意一张（翻面前一定会被换掉）；格子总数不超过 12。
- 卡面圆角 {{radius}}，投影 `0 12px 30px rgba(0,0,0,0.4)`，图片 `object-fit: cover`，加载前底色 `#16161d`。
- 页面在后台时定时器跳过这一拍；`prefers-reduced-motion` 下不起定时器、过渡也去掉，网格静止。

## 完成后请检查

- 翻面时始终只转半圈、方向一致，不会突然倒转一圈回来
- 翻出来的图是列表里的下一张，而不是原来背面那张随手放的
- 页面在后台时不翻；系统开启「减少动态效果」时静止
