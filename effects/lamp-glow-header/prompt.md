## 效果描述

深色页面中央横着一根极细、极亮的灯管，是整个画面唯一的光源。从灯管向上张开一片三角形的柔光，越往上越淡、越宽，像灯管在往上打光；灯管下方还有一团更柔的晕光，把下面的标题也照亮一点。页面打开时是「开灯」的过程：灯管从中间一小段亮起延展到整根，光锥从收拢张开，标题和副标题随后从灯下升起。灯光颜色、光锥宽高、光强、字号都可调。

## 实现提示

一个 flex 纵向居中的舞台。灯管是 2px 高的横条，用 `box-shadow: 0 0 12px 灯色, 0 0 40px 半透明灯色` 做辉光。光锥是一个与灯管同宽、指定高度的矩形，背景用以底边中心为圆心的径向渐变 `radial-gradient(ellipse 100% 130% at 50% 100%, 42% 灯色, 10% 灯色 55%, transparent 80%)`——灯管处最亮、越远越淡，再用 `clip-path: polygon(50% 100%, -8% 0, 108% 0)` 裁成倒三角（尖端在灯管中心、向上张开），注意 `filter: blur(14px)` 要放在外层包裹元素上、clip-path 放在内层——先裁三角再整体模糊，边缘才是软的，反过来模糊结果会被裁出硬边。灯下晕光是一个大圆角椭圆 `filter: blur(60px)`、35% 不透明。开灯动画：灯管 `width 40% → 100%`、光锥 clip-path 从窄三角到全三角、标题 `translateY(24px) → 0` 并淡入，各 0.8s 略有延迟。
