## 效果描述

深色页面偏上横着一根极细、极亮的青色灯管，是整个画面唯一的光源。光从灯管向下照：紧贴灯管处最亮、和灯管一样宽，往下略微张开、迅速变淡，像一束柔光打在墙上；灯管上方只漏出一点极淡的光。标题就坐在这束光里，是银灰色的渐变字（上亮下暗），下面一行小字副标题。页面打开时是「开灯」的过程：灯管从中间一小段亮起延展到整根，光束由窄张开，环境光淡入，标题和副标题随后从下方升起。灯光颜色、灯管长度、光束高度、光强、字号都可调。

## 实现提示

一个 flex 纵向居中的舞台，灯组容器与灯管同宽、高为光束高度，灯管贴在容器顶边。灯管 2px 高，颜色为灯色混 15% 白，`box-shadow: 0 0 6px 灯色, 0 0 18px 灯色, 0 0 48px 半透明灯色` 三层辉光。光束是铺满容器的矩形，背景 `linear-gradient(to bottom, 灯色混白 0%, 55% 灯色 18%, 16% 灯色 55%, transparent)`，用 `clip-path: polygon(0 0, 100% 0, 114% 100%, -14% 100%)` 裁成向下略张开的倒梯形；`filter: blur(30px)` 放在外层包裹元素、clip-path 放在内层——先裁再整体模糊，边缘才是软的。再加两团散射光：一个 130% 宽的大椭圆 `blur(90px)`、28% 不透明，盖住标题区域；灯管上方一条 `blur(40px)`、12% 不透明的极淡光。标题 `margin-top` 为负值（约光束高度的 −25%）让它坐进光里，用 `background-clip: text` 做上亮下暗的渐变字（亮端为标题色，暗端为标题色向底色混 45%）。开灯动画：灯管 `width 35% → 100%`，光束 `scaleX(0.35 → 1)`（origin 顶部中心）并淡入，标题 `translateY(40px) → 0` 淡入，各 0.8–0.9s 略有延迟，曲线 `cubic-bezier(0.2, 0.8, 0.2, 1)`。
