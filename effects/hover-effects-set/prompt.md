## 效果描述

一排按钮，每颗演示一种最常见的悬停效果：放大（整颗微微变大）、上浮（向上抬起并出现投影）、摇摆（左右晃两三下停住）、嗡鸣（快速小幅抖动像手机振动）、向右填充（一层强调色从左边扫满、文字反色）、中心下划线（一条线从中点向两端长出）、百叶窗（填充从中线向上下展开）、翘角（右上角卷起一个小角）。也可以只保留其中一种做正式按钮。时长、强度、颜色、圆角都可调。

## 实现提示

一颗按钮 `position: relative; overflow: hidden`，文字包在 z-index 高一层的 span 里，效果各用一个类：放大 `:hover { transform: scale(1.1) }`；上浮 `translateY(-8px)` + box-shadow；摇摆用一段关键帧依次 `translateX(8, −6, 4, −2, 0)px` 配 ±2° 旋转，悬停时播一次；嗡鸣是 0.15s 的 ±3px 抖动播 3 次；向右填充与百叶窗都用 `::before` 铺强调色，分别 `transform: scaleX(0 → 1)`（origin 左侧）、`scaleY(0 → 1)`（origin 中线），悬停时文字换深色；中心下划线用 `::after` 的 `left: 50%; right: 50% → left: 16px; right: 16px`；翘角用 `::after` 在右上角放一个 `linear-gradient(225deg, 底色 45%, 强调色 50%, 浅色)` 的正方形，从 0 长到 28px。位移与放大量都乘一个「强度」变量。

## 完成后请检查

- 八种效果各自独立、互不干扰；填充类效果文字仍清晰可读
- 摇摆 / 嗡鸣只播一次不循环；离开后全部平滑复位
- 系统开启「减少动态效果」时无过渡与动画
