## 效果描述

右上角一个「菜单」按钮。点开后，几块由暗到亮的色板从一侧接连滑进画面，一块比一块晚一点，像洗牌一样错落铺开；最后一块亮色面板到位后，菜单项带着序号一条条从下方落下来，同样一条比一条晚一点。关闭时整个过程倒着来：菜单项先隐去，面板与色板再依次退出。按 Esc 也能关闭。可选左右哪一侧滑入、色板层数和错落间隔。

## 实现提示

色板与面板都是 position: fixed 的竖条，默认 translateX(±105%) 藏在侧边，打开时给 body 加类让它们过渡到 0；每层用 CSS 变量设 transition-delay = 序号 × 错落间隔，关闭时把延迟顺序反过来。菜单项默认 opacity 0 + translateY(24px)，延迟 = 面板到位时间 + 序号 × 错落间隔；关闭时给很短的延迟先走。按钮用 mix-blend-mode: difference 保证叠在面板上也可读。

## 完成后请检查

- 打开时色板一层层错落滑入、面板最后到、菜单项最后落下；关闭顺序完全倒放
- 快速连点开关不会卡在中间状态；Esc 可关闭，按钮 aria-expanded 同步
- 系统开启「减少动态效果」时直接开合，无滑入与错落
