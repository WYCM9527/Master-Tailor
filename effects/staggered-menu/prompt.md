## 效果描述

右上角一个「菜单」按钮。点开后，几块由暗到亮的色板从一侧接连滑进画面，一块比一块晚一点，像洗牌一样错落铺开；面板到位后，菜单项带着序号从各行底部的遮罩里升起，起初带 10° 倾斜，到位时正好转正。按钮文字上滚换成「关闭」，加号转成叉。关闭时全部倒放；Esc 也能关闭。可选滑入方向、层数和错落间隔。

## 实现提示

色板与面板都是 position: fixed 的竖条，默认 translateX(±105%) 藏在侧边，打开时给 body 加类让它们过渡到 0；每层用 CSS 变量设 transition-delay = 序号 × 错落间隔，关闭时把延迟顺序反过来。菜单项做成「遮罩 + 内层」：外层 overflow: hidden，内层 `translateY(140%) rotate(10deg)`（transform-origin 50% 100%），打开时过渡到 0 / 0°，1s、power4 缓出（cubic-bezier(0.16, 1, 0.3, 1)），延迟 = 面板到位时间 + 序号 × 错落间隔；关闭时给很短的延迟先沉回。开关按钮：两行文字「菜单 / 关闭」叠在 1em 高的窗口里，打开时整体上移 100%；加号是两条 2px 短线，打开时分别转 45° / −45° 变成叉。顶栏（position: fixed，含品牌与按钮）整体用 mix-blend-mode: difference，叠在白面板上自动变黑、在深底上保持白——注意要放在顶栏本身而不是按钮上，fixed 元素自成层叠上下文，子元素的混合模式碰不到下面的面板。

## 完成后请检查

- 打开时色板一层层错落滑入、面板最后到、菜单项最后从遮罩里带倾斜升起回正；开关文字上滚、加号转叉；关闭顺序完全倒放
- 快速连点开关不会卡在中间状态；Esc 可关闭，按钮 aria-expanded 同步
- 系统开启「减少动态效果」时直接开合，无滑入与错落
