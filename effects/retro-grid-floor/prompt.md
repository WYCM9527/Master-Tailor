## 效果描述

一块无限延伸的地面网格铺满画面下半部分：远处的格线越来越密、渐渐隐进地平线附近的一层薄雾里，近处的格子越来越大，最后融进底色。整块地面持续向观者滚来，像开车驶过 80 年代合成器浪潮海报里的霓虹公路。画面中央可放一个大标题浮在网格之上。倾角、格子大小、滚动速度、线色和近处渐隐高度都可调。

## 实现提示

不要用 CSS 3D（`rotateX` 一块巨大的平铺网格）：远处几十条格线会被挤进同一个像素，GPU 采样没有多级纹理，地平线附近会闪成一片噪点。改用一张全屏 canvas 按透视公式自己画：视线水平的相机，地平线定在画面 34% 高处，焦距 f = 0.9 × 画面高，相机高度 `h = 格子 × 2.2 × tan65° / tan(倾角)`（倾角越大相机越低、格子越快贴近地平线）。地面上深度 Z 的一点投影在 `y = 地平线 + f·h / Z`：横线取 `Z = (i + 1 − 相位) × 格子`，相位每秒增加 `8 / 一轮时长`（一轮滚 8 格），只画投影落在地平线以下的；竖线是地面上 `X = j × 格子` 的直线，投影后全部汇聚到地平线中心，从雾底画到画面底边（底边深度 `f·h / (画面高 − 地平线)`）。描边用一条从地平线（透明）到地平线下 14% 画面高（线色）的线性渐变，横竖线共用，远处就平滑地隐进雾里。整体透明度放在容器上，近处再盖一层 `linear-gradient(to top, 底色, transparent 90%)`。dpr 封顶 2，每帧读取 CSS 变量以便调参即时生效。

## 技术要求补充

- 横线 y 坐标取整加 0.5，保证 1px 线不发虚
- 后台标签页（document.hidden）跳过绘制；系统开启「减少动态效果」时相位不再推进，网格静止

## 完成后请检查

- 地平线附近没有闪烁噪点，格线平滑隐入雾中；近处融进底色
- 滚动匀速、首尾无缝；改倾角 / 格子 / 线色即时生效
- 系统开启「减少动态效果」时网格静止但仍显示
