## 效果描述
一叠竖版卡片：{{slides}}。顶层卡片可以被鼠标 / 手指按住拖动，卡片实时跟手平移并随距离轻微旋转（越拖越歪）；拖过 {{threshold}} 松手，卡片就朝那一侧飞出旋转淡出，下一张顶上来；没拖到位就弹簧似的弹回原位。「LIKE / NOPE 印章」为 {{stamps}}：开启时向右拖浮现 {{likeColor}} 的 LIKE 印章、向左拖浮现 {{nopeColor}} 的 NOPE 印章，透明度随拖动距离加深。不碰它时每 {{interval}}自动左右交替甩一张（0 为不自动甩），无限循环。右上角 {{accent}} 数字角标显示进度，卡片圆角 {{rounded}}。

## 技术要求补充
- 支持鼠标拖拽和触摸滑动切换（用 Pointer Events 统一处理）
- 支持键盘操作：容器可聚焦，← / → 切换；聚焦或悬停时暂停自动播放
- 无障碍：容器带 role="region" 和 aria-roledescription="carousel"，每张带 aria-label="第 N 张，共 M 张"
- 页面切到后台时暂停自动播放；系统开启「减少动态效果」时不自动播放、切换为瞬间完成

## 完成后请检查
- 拖动时卡片跟手且随距离旋转；过门槛飞出、不过门槛弹回，手感干脆
- 印章方向正确（右 LIKE 左 NOPE）且透明度随拖动渐显，松手后消失
- 自动甩卡左右交替；键盘 ← / → 分别向左 / 右甩；循环一圈后顺序不乱

## 放在哪
适合投票 / 喜好挑选、每日一句、灵感卡片等趣味场景；窄容器（约 320-400px 宽）效果最佳
