## 效果描述

一个胶囊形的输入框，右端一颗圆形发送按钮。空着的时候，灰色的占位文案每隔几秒换一句：旧的一句向上滑出淡去，新的一句从下面滑进来。你打字后占位消失、发送按钮亮起；按回车或点发送，输入框里的文字不是直接清空，而是整行字变成一片细小的粒子，被一阵风从左往右吹散、越飞越快越淡，几百毫秒后消失无踪，输入框恢复空白。占位文案、翻换间隔、粒子密度、消散速度、颜色都可调。

## 实现提示

表单容器 `position: relative`，里面是真实的 `<input>`（透明底）、一个绝对定位的占位层、一张盖在最上层且 `pointer-events: none` 的 canvas，以及发送按钮。占位翻换：单个 span，先加类 `translateY(−140%) + opacity 0`（0.4s），换文字后放到 `translateY(140%)`（无过渡），下一帧去掉类滑回。消散：提交时把输入文字用相同字体画到一张离屏 canvas 上（与输入框等尺寸、起点对齐 padding），`getImageData` 每隔 2px 采样一次 alpha > 128 的像素生成粒子（位置、向右的速度 0.6–2、微小的纵向速度、透明度 1）；把 input 文字设为透明色；每帧粒子 `x += vx × (1 + 4x/宽)`（越右越快）、透明度按位置递减，逐个 fillRect；全部消失后清空 input 值并恢复颜色。

## 完成后请检查

- 占位文案上出下进地翻换；有输入时占位隐藏、按钮变亮
- 提交后文字化成粒子向右吹散，粒子形状与文字轮廓一致；结束后输入框为空
- 系统开启「减少动态效果」时直接清空不播粒子；缩略图里自动打字、发送、消散循环
