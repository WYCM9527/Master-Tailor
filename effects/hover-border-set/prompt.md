## 效果描述

一排深色按钮，每颗悬停时边框以不同方式变化：原本灰色的内描边渐变成蓝色；底色被抽空只剩一圈蓝边；内侧再浮出一圈细边；一圈蓝边向外扩散并淡去（像水波）；一圈边框从外面收拢到按钮边缘；外框向外撑开一截停住；直角按钮变成圆滚滚的胶囊；一条下划线从左划入；一条上划线从上方滑落进来；四条边瞬间长出。边框颜色、粗细、时长、圆角都可调，也可以只显示其中一种。

## 实现提示

按钮默认用 `box-shadow: inset 0 0 0 粗细 灰色` 做内描边（不占布局），`::before` 铺满按钮、`border-radius: inherit`，各变体只改它。描边渐色：悬停把 inset 阴影颜色换成强调色；抽空留边：默认就是强调色描边，悬停 `background: transparent`；内圈细边：`::before` 的 `inset` 收进「粗细 + 3px」并画边框，opacity 0 → 1；边框外扩：`::before` 画边框，悬停播关键帧到 `inset: -12px; opacity: 0`；边框内收：反过来从 `inset: -12px; opacity: 0` 到 `inset: 0; opacity: 1`；外框撑开：`inset` 过渡到 −8px 并停住；直角变胶囊：`border-radius: 2px → 999px`；左划下划线：`::before` 压成底部一条 `scaleX(0 → 1)`（origin 左）；上划线滑落：按钮 `overflow: hidden`，顶部一条 `translateY(−100% → 0)`；四边长出：`border-width: 0 → 粗细`，过渡 0.1s。
