## 效果描述

给页面加一个「彩虹棱镜」的全屏背景：黑场中央立着一座发光的四棱锥，光谱色沿棱面缓缓流动，像白光被棱镜分出的彩虹。动画方式可选：光谱流动（锥底轻轻拧动）、立体自转（三轴慢转）、跟随鼠标倾斜（带惯性）。尺寸、发光、光谱密度、色相与速度见参数。

## 实现提示

- 用一张全屏 WebGL canvas，对四棱锥 SDF 做 100 步体积行进（raymarching），彩虹由累加发光合成。
- 棱锥 SDF：各向异性八面体 `(|x|/半宽 + |y|/高 + |z|/半宽 - 1) * min(半宽,高) * 0.577` 与半空间 `-y` 取 max，得到上尖下宽的锥体。宽、高的倒数预先算好传 uniform。
- 行进的诀窍是步长 `d = 0.1 + 0.2 * abs(SDF)`——永远走不进表面、始终在表面附近徘徊，每步以 `(p.y + z)` 为相位往四通道累加 `(sin(相位*光谱密度 + vec4(0,1,2,3)) + 1) / d`，距表面越近贡献越大，彩虹就贴着棱面流动。
- 累加结果用 `tanh(o² * glow / 1e5)` 压缩（WebGL1 没有 tanh，用 `(e^2x - 1)/(e^2x + 1)` 手写），亮棱清晰、黑场干净；再叠半强度逐帧噪点打散色带断层。
- 三种动画：光谱流动 = shader 里给 p.xz 乘时间矩阵 `mat2(cos(t), cos(t+33), cos(t+11), cos(t))`；立体自转 = JS 里三轴随机角速度合成欧拉旋转矩阵；跟随鼠标 = 指针偏移映射偏航/俯仰目标角、5% 惯性趋近。
- 色相旋转用 YIQ 矩阵（W + U·cosθ + V·sinθ），整条光谱一起转。

## 技术要求补充

- WebGL1 + 全屏大三角形，无第三方库。
- 像素到世界坐标的比例 `1 / (画布高 * 0.1 * scale)`，resize 时更新。
- 时间累加制，切后台暂停。

## 完成后请检查

- 锥体轮廓清晰、彩虹贴着棱面流动，黑场无灰雾
- 三种动画方式都能正确切换，跟随鼠标模式有惯性不生硬
- 开启系统「减少动态效果」后棱镜定格
