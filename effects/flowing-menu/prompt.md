## 效果描述

几行大字菜单用细线隔开，安静地叠着。鼠标移到某一行上，一条亮色的横带从鼠标进入的那一侧（上方或下方）涌进来盖住整行，带子上是「菜单名 + 小图 + 菜单名 + 小图」不停向左流动的跑马灯，行内原本的大字隐去；鼠标从哪一侧离开，带子就从哪一侧退出去。每行各自独立，快速上下扫过会像波浪一样一行行涌起又退去。

## 实现提示

每行 overflow: hidden，里面叠一层「带子」div（绝对定位铺满），默认 translateY(±101%) 藏在行外，:hover 时过渡到 0；pointerenter/leave 时按鼠标 clientY 相对行中线判断方向，写入 CSS 变量决定藏在上方还是下方。带子内是一条 flex 轨道，内容重复两遍、用 keyframes 把 translateX 从 0 到 −50% 线性无限循环即无缝跑马灯。菜单名在悬停时 color: transparent。

## 完成后请检查

- 带子从鼠标进入的一侧涌入、从离开的一侧退出；跑马灯循环处无跳变
- 相邻行的带子不会串到别的行；小图裁成圆角胶囊形
- 系统开启「减少动态效果」时跑马灯静止、带子直接出现 / 消失
