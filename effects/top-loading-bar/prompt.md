## 效果描述

浅色的浏览器窗口里有一排导航和一页内容。点导航或刷新，页面顶端立刻亮出一截细线，按步进间隔一顿一顿往前挪、越往后挪得越少，头部带一小段光晕，右上角同时转圈，旧内容随之变淡。加载完时细线一口气冲满再淡出，新内容从下方浮上来。

## 实现提示

- 窗口 min(780px, 94vw) × min(480px, 84vh)、圆角 14px；44px 标题栏含三色圆点、IconPark refresh 刷新按钮和 13px 地址栏（tailor.studio/路径）。内容区顶部 56px 导航：粗体站名 + 首页 / 作品 / 手记 / 关于，当前页加深并带 2px 下划线。
- 加载条贴在内容区顶端，高 {{height}}、颜色 {{color}}，整条平移表示进度；{{glow}} 时右端叠 100px 宽的光晕（同色 0 0 10px 与 0 0 5px 投影，旋转 3° 并上移 4px）。{{spinner}} 时右上角一个 18px 转圈（2px 边框只着上、左两边，0.4 秒一圈）。
- 开始时瞬间回到最左再过渡到 {{minimum}}；之后每隔 {{trickle}} 自动前进：不到 20% 加 10%，不到 50% 加 4%，不到 80% 加 2%，不到 99% 加 0.5%，最多到 99.4%；每步线性过渡 {{speed}}。
- 点导航后模拟加载 {{load}}（上下浮动 15%），期间旧内容 40% 不透明；到点换上新内容（从下方 8px 浮上，0.3 秒），加载条过渡到 100%，停 {{speed}} 后用 {{speed}} 淡出。加载中再点只重新计时，加载条不回退。

## 技术要求补充

- 导航用真实链接并阻止默认跳转，当前页标 aria-current；加载中内容区标 aria-busy，加载完用 aria-live 播报打开了哪一页；加载条本身对读屏隐藏
- 推进只用一个定时器，加载完不留循环
- 系统开启「减少动态效果」时加载条按步直接跳、转圈停住、新内容直接出现

## 完成后请检查

- 连续快速点不同导航，加载条只往前不回退，最后只冲满一次
- 冲满淡出后再点，加载条从最左重新出发，不会从右端往回缩
- 关掉头部光晕和转圈后只剩一根细线，换颜色时光晕和转圈一起变
