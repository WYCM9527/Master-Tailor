## 效果描述

一个拟物的文件夹图标：彩色夹体带左上小标签，里面叠着三张从深到浅的纸。鼠标悬停时整个文件夹上浮一点、三张纸探出头来、封口两片向左右斜切张开像被撑开的口。点一下，三张纸各自飞出去摊开——左边那张向左上飞并逆时针转 15°，右边那张向右上飞顺时针转 15°，中间那张直直往上再转 5°，此时悬停任何一张纸它会放大一点；再点一下收回。颜色、大小、纸上的文字见参数。

## 实现提示

- 结构：夹体背板（100×80，`border-radius: 0 10px 10px 10px`，颜色 = 封面色压暗 8%）+ 左上标签（30×10，上圆角）+ 三张纸（绝对定位、`bottom: 10%; left: 50%`，宽分别 70%/80%/90%、高 80%/70%/60%，圆角 10px，颜色 #e6e6e6 / #f2f2f2 / #fff）+ 两片封口（都 `inset: 0`，封面色，`transform-origin: bottom`）。整体用外层容器 `scale()` 放大。
- 悬停：文件夹 `translateY(-8px)`；纸从 `translate(-50%, 10%)` 到 `translate(-50%, 0)` 探头；封口前片 `skew(15deg) scaleY(0.6)`、后片 `skew(-15deg) scaleY(0.6)`——两片反向斜切就是「张开的口」。
- 打开（点击切类）：保持封口张开与上浮，三张纸分别 `translate(-120%, -70%) rotate(-15deg)`、`translate(10%, -70%) rotate(15deg)`（高变 80%）、`translate(-50%, -100%) rotate(5deg)`（高变 80%）；打开态下纸 `:hover { scale: 1.1 }`。
- 所有过渡 0.3s ease-in-out（文件夹上浮 0.2s ease-in）。纸的层级在封口之下（z 20 vs 30），飞出后仍在封口上方是因为位移超出了夹体。

## 技术要求补充

- 纯 CSS 过渡 + 一个点击切类，无需动画库；键盘 Enter/空格也能开合，带 aria-expanded。
- 系统开启「减少动态效果」时去掉过渡直接切换。

## 完成后请检查

- 悬停时封口两片斜切张开、纸探出头、整体上浮
- 点击后三张纸飞出并各自旋转摊开，再点收回
- 纸上的文字可读，颜色参数改变时背板同步变深一档
