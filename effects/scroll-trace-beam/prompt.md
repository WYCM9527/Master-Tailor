## 效果描述

一篇分成几段的长文，正文左侧有一条贯穿全文的细竖线轨道，在每段之间微微左右弯一下。起点是一个空心小圆点。往下滚动时，一束青到紫渐变的光沿着这条轨道向下描画：光的头部始终停在视口约三分之一高的位置，尾部拖着约半屏长、渐渐透明，于是它像贴着你的阅读进度一路往下走；滚回去光束也退回去。段落内容、光头位置、光束长度、三段颜色都可调。

## 实现提示

正文容器 `position: relative`，左侧放一张与正文等高的窄 SVG。路径按各段位置生成：从第一段标题起，每段用一段三次贝塞尔连到下一段起点，控制点交替偏左偏右。同一路径画两遍：底线灰色；光束用 `linearGradient`（`gradientUnits="userSpaceOnUse"`，透明 → 头部色 → 中段色 → 尾部色）描边、`stroke-width 3`。滚动时：头部对应的页面位置 = `scrollTop + 视口高 × 光头比例`，换算成 0–1 的进度 k，`head = 总长 × k`、`tail = head − 视口高 × 光束长度`；用 `stroke-dasharray = (head − tail) 总长` 与 `stroke-dashoffset = −tail` 只显示这一段，并用 `getPointAtLength` 取头尾两点把渐变的两端钉上去。起点圆点在 k > 0 时变亮。

## 完成后请检查

- 光束头部跟着滚动位置走，回滚时后退；尾部渐隐
- 轨道紧贴正文左侧、在段落间有轻微弯曲；窗口尺寸变化后重新布局
- 系统开启「减少动态效果」时不自动滚动，仍随手动滚动更新
