## 效果描述

整屏是一面五列的竖版图片墙。慢慢滚动时和普通网格没什么区别；一旦快速滚动，中间那列紧跟手指、两侧的列越靠外越拖在后面，整面墙的横向对齐被拉成一道弧，同时每张图片都被纵向拉长、横向收窄，像被扯动的橡皮筋；停下滚动后，落后的列陆续追上、图片弹回原比例，重新排成整齐的网格。列数、每列张数、滞后强度、拉伸程度、图片比例都可调。

## 实现提示

真正滚动的是一根看不见的空长条（高度 = 网格高 + 半个视口），网格本身 `position: fixed` 在视口里。把图片按列分组，每列一个容器、纵向放 {{rows}} 张（图片不够就循环取用）；每帧对每列做插值：`col.y += (scrollY − col.y) × k`，其中 `k = 1 / (1 + lag × 6)`，`lag = 中间列滞后 + |列号 − 中心| × 每列递增`——越靠外的列 k 越小、追得越慢，于是快滚时产生错开、停下后逐列回弹；列容器 `transform: translateY(−col.y)`。速度：`vel` 用 0.2 插值平滑每帧滚动增量，`speed = clamp((|vel| × 60 − 700) / 3300)`（每秒 700px 以下不生效，4000px 达满），图片 `scale(1 − 0.3 × speed, 1 + 0.7 × speed)` 通过 CSS 变量写到网格上、再以 0.15 插值平滑。

## 完成后请检查

- 快滚时列间错开成弧形、图片纵向拉长；停下后各列回弹对齐、比例复原
- 慢滚时几乎看不出变形；滚到底部不留大片空白
- 系统开启「减少动态效果」时各列同步、不拉伸；无人滚动时缩略图里自动演示
