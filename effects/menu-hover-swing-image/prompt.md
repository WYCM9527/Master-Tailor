## 效果描述

一列带分隔线的大字菜单，每行右侧一个年份小字。鼠标悬停某一行，行文字变蓝并右移一点，同时一张竖版图片在光标处「跳」出来——从光标来的那一侧滑入——然后像拴在光标上一样跟着走。你左右快速晃动鼠标，图片会随之甩出很大的倾斜角、并且瞬间提亮到发白；停住不动，它慢慢摆正、亮度回落。移到另一行，图片换成那一行的图；离开菜单图片收起。摆角、提亮、跟随紧密度、尺寸、颜色都可调。

## 实现提示

图片容器 `position: fixed`，内部两层：外层 `overflow: hidden` 默认 `translateX(±100%)`、内层背景图反向 `translateX(∓100%)`，显示时都过渡到 0（0.2s ease-out）——正负号由进入时光标的横向移动方向决定，用 CSS 变量 `--from` 写入。每帧 requestAnimationFrame：记录上一帧光标位置算横向速度 `dx`，`dist = min(100, |dx|)`；目标位置 = 光标 − 图片一半尺寸，目标角 = `dist / 100 × 最大摆角`（dx 为负取正角、为正取负角），目标亮度 = `1 + dist / 100 × (最大提亮 − 1)`；位置以「跟随紧密度」插值，角度与亮度以 0.1 插值；写 `transform: translate() rotate()` 与 `filter: brightness()`。悬停进入时先把插值状态直接跳到目标（避免从上一位置飞过来）。

## 完成后请检查

- 图片跟随光标、快速横移时倾斜并提亮，停下后回正回暗
- 切换菜单项时换图；离开菜单收起；进入方向与光标来向一致
- 系统开启「减少动态效果」时不摆不闪只跟随；没有鼠标时缩略图里模拟扫过演示
