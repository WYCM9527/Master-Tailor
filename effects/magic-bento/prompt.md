## 效果描述

一组大小不一的深色格子像便当盒一样拼成一块面板。鼠标移到某一格上，这一格边框上靠近鼠标的一段亮起一道 6px 宽的柔光带、格内泛起淡淡光晕，几颗小星点在格里缓缓上浮闪烁；点一下，从点击处荡开一圈光波盖过整格再消散；格子还会朝鼠标方向微微倾斜、并被轻轻吸过去几像素。鼠标移到相邻格子时，光随之转移、旧格的星点缩小淡出，其他格子安静不动。

## 实现提示

边框光带要够宽：伪元素 `padding: 6px` 配 mask 挖空内容区，径向渐变从中心 80% 强调色、30% 处 40%、60% 处透明。点击：以点击点为圆心、半径 = 到格子最远角的距离，放一个径向渐变（40% → 20% → 透明）的圆，0.8s 内从 scale(0) 放到 1 并淡出，结束后移除。星点在鼠标离开时 0.3s 缩小淡出再移除，不要瞬间消失。

CSS grid 便当布局（部分格跨行跨列）。每格 ::before 用 radial-gradient(半径 at 鼠标局部坐标) 配 mask-composite 只保留 6px 宽的边带作边框光带，::after 同样的渐变做内部光晕；pointermove 时把鼠标坐标换算到每格内部写入 CSS 变量。鼠标所在格按相对位置写 rotateX/rotateY（倾斜幅度 × 2）与几像素 translate；进入新格时生成若干绝对定位的小圆点，用上浮闪烁的 keyframes 随机延迟，离开时缩小淡出后移除；点击格子时从点击点荡开一圈光波。

## 完成后请检查

- 边框光只在鼠标附近的一段亮起，光心随鼠标连续移动；跨格移动时上一格的星点被清理
- 倾斜与吸附幅度符合参数，离开后格子回正
- 系统开启「减少动态效果」时不倾斜、不出星点，边框光仍可跟随
