## 效果描述

一张深色卡片，标题和说明之下有一行大字——半透明的、铺着细点底纹的一句「问题」。鼠标移进这一行并横向移动时，一条发光的紫色竖线跟着光标，竖线左边的区域被「擦开」，露出底下的另一句话——「答案」，其中的关键词用紫色标出；竖线右边仍是问题。左右来回划，答案就跟着显隐。鼠标离开后回到设定的停留位置（默认全部盖住）。两句文字、分界线颜色、停留位置都可调。

## 实现提示

揭示区 `position: relative; overflow: hidden`，里面两层 `position: absolute; inset: 0` 的文字面：上层「问题」半透明白字 + `radial-gradient` 点状底纹，`clip-path: inset(0 0 0 var(--x))`（只保留 x 右侧）；下层「答案」`clip-path: inset(0 calc(100% − var(--x)) 0 0)`（只保留 x 左侧）。再放一条 2px 宽、带 `box-shadow` 发光的竖线在 `left: var(--x)`。pointermove 时把光标在揭示区内的横向百分比写进 `--x`，两个 clip-path 加 0.08s 线性过渡让边缘顺滑；离开时把 `--x` 设回停留位置并隐藏竖线。

## 完成后请检查

- 竖线左边是答案、右边是问题，分界处严丝合缝无重叠
- 竖线紧跟光标；离开后回到停留位置
- 没有鼠标时缩略图里分界线自动来回扫；系统开启「减少动态效果」时无过渡
