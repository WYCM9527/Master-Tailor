## 效果描述

一行横向的小字菜单：首页、作品、关于、日志、联系，当前项是红色，其余灰色、悬停变白。当前项的标记是线条，一个开关切换五种：一根红线在项与项之间滑动、到位时带一点过冲回弹；当前项上下各一根线从相反方向长出把它夹住；四条线依次沿上、右、下、左画出一个框；一根线从文字正中横穿并变粗、文字向上浮开；项两侧各一根竖线从中点向上下长满。悬停即切换当前项（可改为只在点击时切换），也可以用左右方向键切换。颜色、线条粗细、字号都可调。

## 实现提示

`<ul>` 横向排列，每项 `position: relative`，用 `::before / ::after`（项与链接各有一对，共四条）做线条，默认 `scale(0)`。滑动线变体单独放一个 `<li class="mt-line">`，JS 在切换时把当前项的 `offsetLeft / offsetWidth` 写进 `--x / --w`，过渡 `transform 0.5s cubic-bezier(1, 0.01, 0, 1.22)`（这条曲线自带过冲）。夹线：上线 `transform-origin: 0 50%`、下线 `100% 50%`，当前项 `scaleX(1)`。画框：左竖线 origin 底部、上横线 origin 左、右竖线 origin 顶部、下横线 origin 右，`transition-delay` 依次 0 / 0.2 / 0.4 / 0.6s。中线：`top: 50%` 的线 `scaleX(1) scaleY(3)`，文字 `translateY(−0.5em)`。竖线：两侧线默认 `top: 50%; height: 0`，当前项过渡到 `top: 0; height: 100%`。当前项设 `aria-current="page"`。
