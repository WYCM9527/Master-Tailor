## 效果描述

三个只有一条灰色底线的极简输入框：姓名、邮箱、手机，标签文字就躺在输入位置上。点进某一个，标签缩小并上浮到框顶变成蓝色小字，底部一条蓝色的线从中间向两侧画出；输入内容合规（邮箱格式对、手机号 11 位）时右侧一笔描出绿色对勾、底线与标签转绿；内容不合规就离开时，底线变红并左右抖一下。清空内容再离开，标签落回原位。颜色、时长、字号、字段与校验都可调。

## 实现提示

每个字段：`<input placeholder=" ">`（一个空格占位符，让 `:placeholder-shown` 能区分「空」与「有内容」）、紧随其后的 `<label>`（绝对定位在输入位置，`transform-origin: 0 0`）、一条 `.line`（底部 2px，`scaleX(0)`，origin 居中）、一个对勾 SVG。样式全靠兄弟选择器：`input:focus ~ label, input:not(:placeholder-shown) ~ label { transform: translateY(−24px) scale(.76) }`，聚焦时标签变强调色、`.line` 过渡到 `scaleX(1)`（`cubic-bezier(0.2, 0.8, 0.2, 1)`）。校验：input 事件里按类型用正则判断，通过则给字段加 `valid`（对勾 `pathLength="1"` 的 `stroke-dashoffset: 1 → 0`、线与标签换成通过色）；失焦且有内容却不通过时加 `error`（线变红、input 播一段 `translateX` 左右衰减的 0.4s 抖动关键帧）。原生 input 保证键盘与输入法可用。

## 完成后请检查

- 聚焦上浮 / 画线，有内容时标签保持上浮，清空失焦后落回
- 合规出现绿色对勾；不合规失焦抖动变红；再次输入时清除错误态
- 系统开启「减少动态效果」时无过渡不抖动；没人操作时缩略图里模拟输入演示
