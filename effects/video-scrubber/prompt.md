## 效果描述

一个视频播放器，底部是按章节断开成几段的细进度条：已播放的部分是进度色，前面一截浅色是已缓冲，下方是播放按钮、时间和当前章节名，画面随播放缓慢平移。鼠标移到进度条上时条变粗，所在那一章再粗一点，播放头冒出圆点，上方弹出该处的画面预览、章节名和时间，播放头到鼠标之间也被提亮。按住拖动可以跳转，点画面暂停或继续。

## 实现提示

- 播放器宽 min(760px, 92vw, 86vh × 16 / 9)、16:9、圆角 {{radius}}；{{slides}} 每张一章，时长按权重 1.3 / 2.2 / 1.6 / 0.9 / 1.4 / 1.1 循环分配，总和 {{duration}} 秒。当前章的图铺满（取景点 50% 40%）、放大 1.08 倍，随章内进度从 +1.5% 平移到 −1.5%。
- 底部 42% 高渐变压暗（透明到 72% 黑）；控制区左右内边距 14px，20px 热区放进度条，下面 40px 一行：播放按钮（IconPark pause / play-one）、「当前 / 总时长」、「· 章节名 >」（IconPark right）。
- 进度条：{{chapters}} 为真时每章一段（宽按章节时长分配，段间距 3px），否则一整段；段高 {{height}}、底色 22% 白，内叠三层原点在左的 `scaleX`：缓冲 38% 白、悬停 50% 白（到鼠标处）、已播放 {{color}}。缓冲最多领先 30% 时长，每秒缓冲 18 秒。
- 悬停：段高乘 {{grow}}，所在段再乘 1.35（0.1s）；13px 圆点跟着播放头，悬停 / 拖动时从 0 放大到 1。预览框宽 min({{size}}, 36%)、16:9、2px 白边、圆角 8px，底边离控制区底 68px，对准鼠标、两侧留 8px；{{preview}} 为真时显示该章图片（背景宽 150%，横向位置随章内进度 20% → 80%），下接章节名和时间。

## 技术要求补充

- 点画面或按钮切换播放，画面中央 64px 圆底图标 0.5s 放大到 1.6 倍并淡出；{{autoplay}} 为真时开场就播，播完从头循环
- 时间与横坐标互换按各段实际位置计算（扣掉段间缝），落在缝里吸到较近一端；几何只在尺寸变化时量
- 进度条带 role="slider" 与 aria-valuenow / aria-valuetext；播放器可聚焦：空格或 K 播放 / 暂停，← / → 跳 5 秒，J / L 跳 10 秒
- 拖动用 Pointer Events 并 setPointerCapture，拖出进度条也能继续；松手时指针在条外就收起预览
- 页面切到后台时不推进；系统开启「减少动态效果」时画面不平移、加粗直接切换、不闪播放图标

## 完成后请检查

- 圆点、已播放、悬停提亮三者在段间缝两侧对齐，圆点不会停在缝里
- 预览框贴近两端时被夹在播放器内，不会被裁掉
- 拖动时画面和章节名跟着变，松手后从新位置接着播放
