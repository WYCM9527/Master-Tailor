## 效果描述

一颗蓝色胶囊按钮。默认变体：点击的瞬间整颗按钮（连文字）像被电流击中——边缘扭成波浪、笔画错位抖动，约 0.4 秒后恢复平整，扭曲先加剧再平息。另一变体在悬停时触发：按钮底色横向弹性拉伸一下再回弹，同时从左右两侧各甩出三滴同色的小液滴，液滴与按钮边缘黏连在一起再脱开，鼠标离开后收回。扭曲强度、褶皱细密度、时长、颜色、圆角都可调。

## 实现提示

扭曲变体：SVG 滤镜 `feTurbulence(fractalNoise, numOctaves 1)` → `feOffset(−90, −90)` → `feDisplacementMap(scale = 强度, in2 = 位移图)`。点击时给按钮容器加 `filter: url(#滤镜)`，用 requestAnimationFrame 在设定时长内把 `baseFrequency` 从 0.000001 线性升到峰值再降回（各占一半），结束后移除 filter——滤镜常开会让文字发糊。液滴变体：底色层与六个小圆点放进同一个套着粘液滤镜（`feGaussianBlur 7` + alpha 矩阵 `19 −9`）的容器；悬停时底色 `scaleX(1.06)` 用 `cubic-bezier(0.34, 1.56, 0.64, 1)` 过冲回弹，小圆点分别过渡到各自的位移与缩放（延迟 0 / 60 / 120ms），离开时归零。文字层在滤镜容器之外，保持清晰。

## 完成后请检查

- 点击扭曲：先加剧后平息，结束后完全恢复、文字清晰
- 悬停液滴：底色弹性拉伸，液滴与按钮边缘有黏连再脱开的过程
- 系统开启「减少动态效果」时不扭曲、不甩液滴
