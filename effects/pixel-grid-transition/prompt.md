## 效果描述

两页全屏内容（各一张压暗的图和一个大标题）。点击换页时，整屏被一格格白色像素块铺满：从最上面一行开始，一行行向下翻亮，但每格都带点随机的先后，波前是参差不齐的锯齿，不到一秒盖满全屏；盖满的那一瞬底下换成了新页；然后像素块按相反的顺序一格格褪去，新页从下往上显露。铺开顺序可换成完全随机、对角线或从中心向外。行数、延迟、单格时长、格子颜色都可调。

## 实现提示

像素格层是一个 `position: fixed; inset: 0` 的 CSS Grid，行数由参数决定、列数按视口宽高比取整让格子近似正方；每格默认 `opacity: 0; transform: scale(0.6)`，过渡 `cubic-bezier(0.7, 0, 0.3, 1)`。建格时给每格算一个「档位」：从上到下 = 行号 + 0–5 的随机数，随机 = 随机数，对角 = 行号 + 列号 × 行列比，中心 = 到中心的距离；延迟 = 档位 × 相邻档延迟。换页流程：① 写入正向延迟、加类让全部格子翻亮，等 `最大档位 × 延迟 + 单格时长`；② 用 `document.startViewTransition(切换两页的 hidden)` 原子换页（CSS 里把 `::view-transition-old/new(root)` 的默认动画关掉，视觉全交给像素格），不支持该 API 时直接切换；③ 写入反向延迟、去掉类让格子褪去。

## 完成后请检查

- 铺开时波前参差、盖满后才换页、褪去顺序与铺开相反
- 四种顺序各自成立；格子铺满全屏无缝隙
- 系统开启「减少动态效果」时直接换页不播像素格
