## 效果描述

一个四行高的小「井」。方块一块块从井口落下：每块随机选一列，加速落到那一列最高的空位停住、留下一个亮格。当某一行被填满，整行先闪一下白光、缩小消失，上面的方块顺势落下一层；如果堆到了顶，整井清空重新开始。像一局自动进行、永远打不完的俄罗斯方块。格数、格子大小、下落速度、颜色都可调。

## 实现提示

一个 CSS Grid 的「井」（cols × 4 格，每格一个默认透明的 div），另用一个绝对定位的方块 div 表示正在下落的块：设置它的列、在下一帧把 `top` 过渡到目标行（`cubic-bezier(0.5, 0, 1, 0.5)` 加速下落），过渡结束后移除它并把目标格设为亮。维护一个布尔矩阵记录占位：落点 = 该列从下往上第一个空位；行满时给井加 `flash` 类让该行格子播「变白放大→缩小消失」的关键帧（其他格子暂时禁用动画），300ms 后把上面的行整体下移一层；首行有格子被占则清空重来。

## 完成后请检查

- 方块加速下落、准确落到该列最高空位；满行闪光消除并整体下移
- 堆到顶自动清空；格数改变后井宽随之变化
- 系统开启「减少动态效果」时不再落块
