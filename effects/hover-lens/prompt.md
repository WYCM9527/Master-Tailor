## 效果描述

一张带标题说明的图片卡。鼠标移进图片，光标处立刻浮出一枚圆形放大镜：镜中是同一张图放大两倍后的画面，正好对着光标所指的位置，像隔着一块凸透镜看照片；移动鼠标，镜片和镜中的画面一起跟着走，镜片边缘有一圈细白边。鼠标离开时镜片缩小消失。放大倍数、镜片直径、镜圈颜色粗细、图片圆角都可调。

## 实现提示

取景区里叠两层同一张图：底图正常显示；上层放大层 `position: absolute; inset: 0`，里面的图 `transform: scale(倍数)`、`transform-origin` 设为光标坐标，这样放大后光标所指的点仍在原位。放大层用 `mask-image: radial-gradient(circle 半径 at x y, #000 100%, transparent 100%)` 只露出光标周围一个圆。三处坐标（遮罩圆心、缩放原点、镜圈位置）共用一组 CSS 变量 `--x / --y`，pointermove 时相对取景区左上角写入。进入时放大层从 `opacity 0; scale(0.58)` 过渡到 `1; scale(1)`（0.12s），离开时反向。镜圈是一个跟随的空心圆 div。

## 完成后请检查

- 镜中放大的画面与光标所指位置严格对应，不会「对不上」
- 镜片跟手无迟滞；进入 / 离开有缩放淡入淡出
- 按 Esc 或鼠标离开后镜片消失；没有鼠标时缩略图里镜片自动巡游
