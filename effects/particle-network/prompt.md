## 效果描述
一片铺满容器的星空：许多小粒子按漂移速度缓慢游走，碰到边缘反弹。任意两个粒子靠近到连线距离以内时，它们之间出现一条细线，越近越实、拉远时渐渐消失，整体像一张会呼吸的星图。鼠标移入时如同引力源，周围稍大范围内的粒子都会与鼠标位置连线，随着移动牵起一片线网。

## 实现提示
- 一张 `position: fixed; inset: 0` 的全屏 canvas 2D + requestAnimationFrame；分辨率跟随 devicePixelRatio（上限 2，`setTransform(dpr, 0, 0, dpr, 0, 0)` 后仍按 CSS 像素作图）；窗口 resize 时重设画布尺寸（粒子坐标不重算）。
- 粒子：{{count}} 个，初始位置在画布内随机；速度每轴 `(random − 0.5) × 漂移速度倍率`（倍率取 {{speed}}，单位 px/帧，按帧推进不乘 dt），之后大小不变。每帧 `x += vx; y += vy`，越出左右边 `vx *= −1`、越出上下边 `vy *= −1`，简单反向、不夹回边内。
- 每帧先 `clearRect` 整张画布再重画，没有拖影；粒子画成半径 1.6px 的实心圆，颜色 {{color}}。
- 连线：双重循环遍历所有粒子对（i < j），距离小于连线距离（{{linkDist}}）才画：`lineWidth: 1`，颜色是粒子色转成的 rgba，alpha = 连线浓度（{{lineAlpha}}）× (1 − 距离 / 连线距离)，贴得最近时最实、到达连线距离时正好透明。
- 鼠标视作「第 N+1 个粒子」，但连线范围放大到连线距离 × 1.4：每个粒子到鼠标点的距离小于该值就从粒子连到鼠标，alpha = 连线浓度 × (1 − 距离 / (连线距离 × 1.4))；鼠标本身不画点。初始与 `mouseleave` 时把鼠标坐标设到 (−9999, −9999)，自然不会有线。
- 颜色与连线浓度每帧从 CSS 变量读取（十六进制拆成 r, g, b 再拼 rgba），调参实时生效，不必重建粒子。
- 页面切后台 `cancelAnimationFrame` 暂停、回到前台再续；系统开启「减少动态效果」时跳过位置更新、只画一帧（连线仍按当时距离计算）。

## 完成后请检查
- 粒子数量、颜色、漂移速度、连线距离与浓度和参数一致；线的透明度随距离平滑变化
- 鼠标移动时周围粒子与鼠标连线，移开后连线消散；窗口改变大小后画布自适应不变形
- 页面切到后台时动画暂停不耗电；系统开启「减少动态效果」时只显示一帧静态星图
