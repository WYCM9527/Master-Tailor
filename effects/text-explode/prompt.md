## 效果描述

一句粗体大字。触发后分三步：先整句向内紧缩、字距收窄，每个字微微左右抖动，像在蓄力；然后「砰」地炸开——每个字朝不同方向飞出去，边飞边翻滚、放大、变淡，弧线先上扬再下落，直到消失；最后整句从下方约 50px 处轻轻浮回原位，恢复如初。可以自动循环，也可以点击或悬停触发。力度、时长、停顿、字号、颜色都可调。

## 实现提示

把文字拆成一个个 `<span>`（inline-block）。用 Web Animations API 串三段：① 整句容器 `scale(1 → 0.82)`、`letter-spacing → −0.12em`（ease-in，占总时长 28%），同时每个字符播一段随机 ±3px 的抖动关键帧；② 每个字符一条四关键帧的轨迹：位移 x 为随机方向 × (20–80) × 字数 × 力度，y 先按它在句中的位置 `−sin(i/(n−1) × π) × (40–160)` 上扬再落回正值，旋转到随机 ±360°，缩放到 1.2–2.8，透明度 1 → 0，`cubic-bezier(0.2, 0.6, 0.4, 1)`，占 72%；③ 全部结束后取消上述动画，整句 `translateY(50px) + opacity 0 → 0 + 1`（0.5s）。用 `animation.finished` 的 Promise 衔接各段。

## 完成后请检查

- 三段依次发生：紧缩抖动 → 各字四散翻滚淡出 → 从下方浮回
- 中间的字飞得更高、两端的字更低（弧形分布）；每次随机方向不同
- 系统开启「减少动态效果」时不播动画
