## 效果描述

几张卡片像一叠悬浮的玻璃板，以等轴测的视角（从上方俯视、再在桌面上斜转）一层层垫开，彼此留着相同的间隔，带着柔和的投影。「级联穿过」时卡片沿着叠放的方向源源不断地穿过：最底一张淡入、逐层上升、到顶淡出；「轮流聚焦」时轮到哪一张，它就抬起来、转正朝向观者停一会儿再落回；「整叠环绕」时整叠卡片绕竖轴缓缓旋转。不需要任何操作，永不停歇。

## 实现提示

- 结构：全屏舞台 `perspective: 1400px`；等轴测锚点 `scale(适配比) rotateX({{tiltX}}) rotateZ({{tiltZ}})`，`transform-style: preserve-3d`；里面一层可选的环绕容器，再放 N 张卡（N 为图片张数，最多 8）。第 i 张沿法线抬高 `(i − (N − 1) / 2) · {{layerGap}}`（`translateZ`），卡宽 {{cardWidth}}、4:3、用负外边距对中；投影 `0 30px 60px rgba(0,0,0,0.45)`（{{shadow}} 关闭时透明度乘 0）。
- 级联穿过：每张卡 `translateZ(−范围 → +范围)` 线性无限，范围 = N / 2 × 层间距，时长 {{speed}}，第 i 张 `animation-delay = −i · 时长 / N`（任一时刻恰好等距）；关键帧 0–12% 淡入、88–100% 淡出。
- 轮流聚焦：不用关键帧，JS 每 {{speed}} / N 秒（不短于 0.9s）给下一张加类：`translateZ(原高度 + 140px) rotateZ(−平面旋转) rotateX(−俯视角)`——反向抵消两个视角旋转就正对观者；`transition: transform 0.9s cubic-bezier(0.2, 0.8, 0.2, 1)`。
- 整叠环绕：环绕容器 `rotateZ(0 → 360deg)` 线性无限、时长 {{speed}}，在等轴测平面内转就是绕竖轴环绕。
- 适配：卡片对角线 + 0.6 × N × 层间距 占画面短边的 86%，按此缩放（小屏缩小、大屏最多放大 1.2 倍），resize 重算。卡片圆角 {{radius}}，图片 `object-fit: cover`，加载前底色 `#16161d`。
- 页面切后台把动画 `animation-play-state: paused`、定时器跳过；`prefers-reduced-motion` 下去掉动画与过渡、不起定时器，叠卡静止。

## 完成后请检查

- 级联穿过时相邻两张始终等距，淡出的一张与淡入的一张同时发生，看不出「补位」
- 轮流聚焦时抬起的卡片正对观者且不歪，落回后回到原来的层
- 页面在后台时暂停；系统开启「减少动态效果」时叠卡静止
