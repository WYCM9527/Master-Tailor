## 效果描述

鼠标在空白区域里移动，每走过一小段距离，身后就冒出一张图片：它从鼠标滞后一点的位置出现、顺着运动方向滑到鼠标所在处停住，带着随机的小倾斜，新的压在旧的上面；停留一会儿后依次缩小淡出。图片按列表顺序轮流出现，同屏数量有上限，最早的先被顶掉。移动越快，身后拖出的图片带越长。

## 实现提示

位移感的关键：维护一个每帧以 10% 速率追鼠标的「滞后点」，新图从滞后点出现，在前 40% 时间里（easeOutQuad，`cubic-bezier(0.25, 0.46, 0.45, 0.94)`）滑到鼠标当前位置，40%–60% 原地停留，最后 40%（easeOutCubic，`cubic-bezier(0.215, 0.61, 0.355, 1)`）缩到 0.2 并淡出，整条时长即停留时间 {{lifetime}}——用 CSS 变量 --x0/--y0（滞后点）与 --x1/--y1（鼠标点）写进关键帧的 translate。鼠标甩得越快滞后点落得越远，图片滑行的距离越长、方向越明确。

监听 pointermove，与上一次冒图位置的距离超过「出现间距」就在当前位置插入一张绝对定位的 img（translate(-50%,-50%) 居中，z-index 递增让新图在上），并给它同一条 keyframes（`forwards` 填充）：0% 在滞后点、不透明、`scale(1)` → 40% 到鼠标点 → 60% 原地保持 → 100% `scale(0.2)` 并透明；`rotate(--rot)` 全程不变，`--rot` 是 ±{{tilt}} 内的随机角；animationend 后移除节点，超过同屏上限先移除最早的。图片地址预加载避免首帧闪白。

## 完成后请检查

- 图片沿鼠标轨迹按间距冒出，新图始终压在旧图之上，倾斜角各不相同
- 每张图停留后都会消失，节点不会无限堆积；同屏数量不超过上限
- 系统开启「减少动态效果」时不冒图
