## 效果描述

多款滑块皮肤上下排开：镂空压在风景照上，圆环拇指和轨道之间留着透明间隙；霓虹在深色底上越往右越亮；胶囊数值把数字写在拇指里；刻度尺下方排着刻度；拟物凹槽是浅灰底上的凹槽配凸起圆钮。拖动时走过的刻度依次点亮、霓虹光晕跟着变大，点轨道则带着轻微回弹跳过去。开启联动时拖任何皮肤，其余皮肤同步跟着走；按住时镂空圆环填满、胶囊微微放大。

## 实现提示

- 卡片宽 min({{width}} + 168px, 94vw)，每块圆角 18px，左皮肤名右数值；{{skin}} 选单一皮肤时只留那块、隐藏皮肤名。
- 原生 range 透明铺满滑块区，负责拖动、键盘和读屏；它的拇指宽设为该皮肤拇指宽 S，外观按拇指中心 S/2 + v·(宽 − S) 摆放，指哪到哪。
- 当前值注册成 @property 数字：单击轨道或按键时 0.32 秒 cubic-bezier(.3,1.35,.5,1) 回弹过渡，按住后一移动就关掉过渡跟手。
- 镂空：日落风景底图（渐变天空、太阳、山丘），线粗 {{thickness}}，在拇指两侧各断开 {{gap}}；拇指是 {{size}} 圆环、环宽等于线粗，{{color}} 悬停加深 18%，按住时环宽 0.3 秒涨满。
- 霓虹：深色底，填充从半透明主色渐到偏白，光晕和亮度随 v 增大并乘 {{glow}}，拇指下映出一团光。
- 胶囊数值：轨道高 12px + 线粗 × 2，拇指为 56px 白药丸、内写数值，按住放大 1.08。
- 刻度尺：每 5% 一根刻度、每 25% 长刻度带数字，走过的点亮；指针 3 × 26px，顶着数值标签。
- 拟物凹槽：内阴影压出凹槽，圆钮用双向阴影凸起、嵌一颗主色灯，按住时阴影收小。
- {{sync}} 时拖任一条全部同步，否则只改当前条；打开时从 0 弹到 {{value}}。

## 技术要求补充

- 每条都是原生 range，带「镂空皮肤滑块」这类 aria-label 和带 % 的 aria-valuetext，方向键、Home / End 都可用
- 系统开启「减少动态效果」时跳值不过渡，按下态直接切换

## 完成后请检查

- 指针按在外观拇指上拖动时数值不跳，拖到两端正好是 0 和 100
- 镂空间隙里能透出底图，不是实心色
- 关闭联动后只有被拖的那条变化
