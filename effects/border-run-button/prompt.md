## 效果描述

一颗深色按钮，边框不是静止的线，而是一段紫到青的亮色光带，沿着按钮轮廓一圈圈地跑，其余部分的边框是暗的。鼠标悬停时光带明显变长、跑得更快，像一圈追光灯在绕着按钮转。文字、两个光带颜色、边框宽度、速度、圆角都可调。

## 实现提示

按钮 `position: relative; isolation: isolate`。`::before` 比按钮向外扩出边框宽度、z-index −1，背景是 `conic-gradient(from var(--角), transparent 0 70%, 第二色 82%, 主色 92%, transparent)`；再用 `::after` 铺一层与按钮同尺寸的底色盖住中间，只在边框缝里露出渐变。角度用 `@property --mt-a { syntax: '<angle>' }` 注册成可动画属性，关键帧 `to { --mt-a: 360deg }` 线性无限——渐变整体绕中心转，缝里那段亮色就成了跑动的光带。悬停时换成透明段更短的渐变（光带更长）并把周期除以 2.5。

## 完成后请检查

- 光带沿轮廓连续跑动、圆角处不断裂；其余边框为暗
- 悬停时光带变长变快；移开恢复
- 系统开启「减少动态效果」时光带静止
