## 效果描述

一墙图片卡片整齐排着，默认全部是暗沉的黑白。鼠标移上去，以鼠标为中心的一圈范围内颜色被「照亮」还原：圈内是彩色原图、圈外仍是黑白，边缘按柔度渐变过渡，像拿着手电在暗房里照一墙照片。每张卡有自己的专属颜色：卡底是该色压暗到黑的渐变，悬停时整圈描边亮起这个颜色，卡内还有一团跟着鼠标走的白色高光；靠近鼠标的那段边框也会亮起一道白光。聚光圈跟着鼠标走并带一点迟滞，移出后整墙重新沉回黑白。

## 实现提示

每张卡分配一套专属色（如靛蓝 / 翠绿 / 琥珀 / 红 / 紫 / 青，按序循环）：卡底是「该色 → 黑」的斜向渐变（角度各不同），图片略透（opacity 0.92）让底色隐约透出；卡片默认 1px #333 描边，悬停时描边过渡成该卡的专属色；卡内叠一层 `radial-gradient(circle at 鼠标, rgba(255,255,255,0.3), transparent 70%)` 的高光，悬停时淡入、随鼠标移动。

不要逐张改滤镜——在整墙上盖一层 pointer-events: none 的「去色罩」，用 backdrop-filter: grayscale(1) brightness(0.6) 把底下变成黑白，再用 mask: radial-gradient(circle 半径 at 鼠标位置, transparent → #000) 在鼠标处挖一个洞（transparent 的位置由柔度决定），洞内就露出原色。鼠标坐标每帧按迟滞插值后写入 CSS 变量。边框亮光用卡片 ::before 的 radial-gradient 配 mask-composite 只留 1px 描边。

## 完成后请检查

- 圈内彩色、圈外黑白，边缘过渡符合柔度；圈跟随鼠标有迟滞不甩动
- 边框光只亮靠近鼠标的一段；鼠标移出后整墙变回黑白
- 系统开启「减少动态效果」时聚光圈直接跟手不做迟滞
