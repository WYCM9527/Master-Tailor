## 效果描述

聚光灯质感的舞台中央立着一枚硕大锐利的主字，字身上不压任何文字，只在下方配着小标题与两行摘要；其余大字并没有消失，而是在主字左右后方以夸张的侧翻角度与俯仰倾角斜立着，化作几道柔焦模糊的深色残影。每隔一段轮换间隔，前景主字向侧后方偏轴翻走并失焦没入暗影，右侧待命的残影顺势旋回正面、在切换时长内拉清对焦，底部说明同步滑入换新。点击舞台左右半区、横向拖拽或点底部圆点都能随时切到任意一项，像镜头在立体字阵间变焦追光。

## 实现提示

核心诀窍是「外层全幅模糊 + 内层广角偏轴三维翻转 + 累加游标」：如果把高斯模糊与三维旋转写在同一个窄盒子上，广角拉伸后的笔画会被盒子边缘硬生生裁断；拆成铺满舞台的外层槽位负责模糊与透明度、内层字块负责三维姿态，就能完美还原演示软件里「贴透明占位框偏轴旋转 + 艺术虚化 + 平滑切换」的立体散景质感。

- 舞台容器：`width: min(940px, 94vw)`、`aspect-ratio: 16 / 9`、`max-height: 90vh`、圆角 16px、`container-type: size`，阴影 `0 24px 72px rgba(0,0,0,0.42)`；底衬用椭圆径向渐变模拟聚光灯，从中心（{{stageColor}} 混 14% 白）过渡到 34% 处的 {{stageColor}}，再到四周暗角（{{stageColor}} 混 68% 的 #14130f）。
- 条目解析：按「｜」切分 {{items}}，每段按「=」拆出「大字 / 标题 / 说明」。维护不取模的累加整数游标 `cursor`，第 `i` 项的连续圆周相位 `u = (i - cursor) / 总数`、`phi = 2π·u`，圆周深度因子 `depth = (1 - cos(phi)) / 2`（正前为 0，左右两侧为 0.5，正后方为 1）。
- 偏轴三维姿态与景深：内层大字用高对比衬线字族（Didot / Times New Roman / Songti SC）、900 字重、字号 `52cqh`、色取 {{glyphColor}}，定位在 `left: 50%; top: 43.5%`。横移 `tx = sin(phi) × 舞台宽 × 0.175`（模拟透明辅助框带来的偏心公转半径），上浮 `ty = -depth × 舞台高 × 0.022`；竖轴旋转角 `rotY = 360 × u + ({{tiltAngle}} - 90) × sin(phi)`（单调连续，跨整圈绝不反向回弹，两侧恰好翻至 ±{{tiltAngle}}），横轴俯仰 `rotX = sin(phi) × {{pitchAngle}}`，透视距离取 {{perspective}}，后方缩放 `1.12 + sin²(phi) × 0.14`。外层全幅槽位设 `filter: blur({{blurAmount}} × (0.85 + depth × 0.55))`（正前为 0px）；因两侧大字侧翻变窄后模糊会稀释浓度，透明度取 `0.2 + sin²(phi) × 0.62 + (1 - depth) × 0.12`（正前为 1，左右两侧浓郁立体，正后方化作轻柔暗晕）。补间曲线统一 `cubic-bezier(0.22, 1, 0.36, 1)`、时长 {{duration}}。
- 底部说明：主字上不叠加任何文字，标题只出现在底部说明区。说明区（`bottom: 8.5%`、宽 `min(520px, 78%)`、标题 `3.1cqh`、正文 `2.25cqh` 两行截断、色取 {{glyphColor}}）按当前激活项切换 `is-active` / `is-prev`，做 ±24px 的微移与模糊淡入淡出。底部 `2.6%` 处放 6px 圆点指示器，当前项拉宽为 20px 胶囊。
- 自动轮换按 {{interval}} 定时递增 `cursor`（为 0 时关闭），用 `ResizeObserver` 缓存舞台宽高避免切换时强制同步布局。

## 技术要求补充

- 支持 Pointer Events 横向拖拽切换（滑动超过约 42px 翻页，轻点舞台左/右半区分别切上一项/下一项）与底部圆点直达
- 舞台可聚焦，支持左右方向键切换；鼠标悬停、键盘聚焦或标签页切到后台时自动暂停轮换，移开后恢复
- 系统开启「减少动态效果」时关闭自动轮换，所有切换改为无过渡瞬间到位

## 完成后请检查

- 首尾循环跨越最后一页回到第一页时，后方大字顺着原方向连续转满整圈，不会反向甩回或闪现横穿画面中央
- 后方大角度侧翻拉伸的大字模糊边缘柔和自然，四周没有被矩形容器硬边切断的痕迹
- 主字上没有任何叠字，底部说明的切换节奏与主字对焦完全同拍，长摘要两行截断后不溢出说明区
