## 效果描述

页面顶部一条浅色的胶囊形导航条，里面并排几颗同样是胶囊形的按钮，左侧可以带一枚圆形徽标。鼠标移到某颗胶囊上时，一团深色的圆从胶囊底部中央涨起来，几百毫秒内把整颗胶囊填满，文字同时向上滚出、一份反色的字从下方滚上来接替；移开后圆缩回底部消失、文字滚回。页面刚打开时，胶囊从零宽依次撑开、徽标从一点放大出现。鼠标在整条导航上时徽标慢慢转一圈。当前页的胶囊下方外侧带一个与填色同色的圆点。

## 实现提示

文字用「双层堆叠」做上滚换行：两份同样的字叠在一个 overflow: hidden 的行内块里，悬停时原字 translateY 到 −(100% + 8px) 滚出、反色副本从 +(100% + 8px) 滚到 0 并淡入。选中点是胶囊下方外侧（bottom −6px）一个 12px、与填充同色的圆。首屏展开：先给所有胶囊 width 0 / padding 0 并把徽标 scale(0)，下一帧撑开到量好的自然宽度（0.6s，power3 缓出），徽标放大到 1。

胶囊 button 设 overflow: hidden、isolation: isolate，用 ::before 画一个宽 160%、正圆的伪元素，定位在底部中心并 translate(-50%, 100%) scale(0.2) 藏在下方；:hover 时过渡到 translate(-50%, 0) scale(1.1) 盖满，transition 时长即涨起时长，文字层 position: relative 叠在上面并过渡颜色。当前项用 ::after 画小圆点，徽标 :hover 时 rotate(360deg)。

## 完成后请检查

- 涨起的是一团从底部中心长大的圆，边缘被胶囊裁成弧形，不是整块矩形变色
- 快速在胶囊间移动时每颗各自涨起收回，互不影响；当前项圆点位置正确
- 系统开启「减少动态效果」时悬停直接变色不涨起，徽标不转
