## 效果描述

整屏是一张海报，像立方体朝向你的那一面。点「下一面」，整个画面立体地转动一格：当前页贴着左侧棱边向左折转出去，新页同时贴着右侧棱边从右边转进来，两面在转动中各带一点侧光变暗，立体感由纵深感决定，折转的幅度由折面角度决定。返回时立方体原路转回。整个过程像在手里转动一只方盒子看另一面。

## 技术要求补充

- 用同文档 View Transitions（document.startViewTransition）实现：切页前在 html 上标记方向（前进/返回），返回是前进的严格镜像
- 两面必须同时同曲线折转（一个转出一个转入），棱边处两面拼合自然；转动中两面带轻微压暗交代侧面受光
- 浏览器没有该 API 时降级为 CSS 类动画（两面同框播同一套动画），视觉一致；开启「减少动态效果」时一律瞬间切换
- 如果要在多页应用（两个独立 HTML）之间做同款转场：两页同源，各自声明 @view-transition { navigation: auto }（Chrome 126+ / Safari 18.2+，Firefox 暂不支持，需接受直接切换降级）

## 实现提示

两面是同文档里互斥显示的两块海报（hidden 切换）。转场期间给离场页与进场页都挂 view-transition-name: page。快照上无法共享 3D 舞台，透视要写进每一帧的变换里：perspective(纵深) translateX(±100%) rotateY(±角度)。前进时 new 快照 transform-origin 设 left center 从右转入、old 设 right center 向左转出；返回镜像互换。折转两端配 0.35 左右的透明度模拟侧面背光。无 API 回退：同一套 keyframes 以类名加在真实页面上（真实元素记得 backface-visibility: hidden）。

## 完成后请检查

- 转动时两面在棱边处的运动方向一致，看起来是同一只盒子在转，不是两张纸各自飞
- 前进与返回是严格镜像；折面角度调到 90 度时是标准立方体直角
- 不支持视图过渡的浏览器里翻面依然成立；开启「减少动态效果」后为瞬间切换
