## 效果描述

一颗透明底的大按钮，本体几乎看不见，只有边缘挂着一圈很淡的暗描边和两段对称的镜面细光——像金属边框在灯下反光的那两段亮边。光的方向会追着鼠标转：鼠标在按钮外时高光朝向鼠标，在按钮上时落在对角线附近随位置微摆；关闭常亮后只有鼠标靠近才逐渐亮起。文字、圆角、高光颜色 / 强度 / 段长 / 羽化 / 粗细、闲置转速见参数。

## 实现提示

- 按钮本体是普通 `<button>`（透明背景、圆角、一点内高光与投影、按下 scale 0.97）；在它上面叠一张 `pointer-events: none` 的 WebGL canvas，四周比按钮各大 20px 留出羽化空间。
- 着色器核心是圆角矩形 SDF：`q = |p| − 半宽高 + r; d = len(max(q,0)) + min(max(q.x,q.y),0) − r`，d 就是到按钮边缘的带符号距离。
- 暗底边：`(1 − smoothstep(0, 1px, |d|)) × 0.45 × 底色`。
- 镜面细光 = 三个因子相乘：①沿边缘的高斯细线 `exp(−k·(d/粗细)²)`，k 在外侧略大让外缘衰减更快；②角度窗口——用「椭圆法线」`normalize(p / 半宽高²)` 与光向 L 的夹角 `phi = acos(|dot|)`（取绝对值让朝光与背光两侧对称），`rim = 1 − smoothstep(段长 − 羽化, 段长 + 羽化, phi)`；③`edgeClamp` 把光钳在边缘 3px 内。乘强度与靠近亮度后乘高光色。
- 光向角：指针在按钮外 → `atan2(cy − y, x − cx)`；在按钮内 → 对角线角 `atan2(2/h, −2/w)` 加 `nx×0.3 + ny×0.15` 微摆。目标角按最短路径以 `1 − e^(−7dt)` 追近；无指针时以「闲置转速」自转。亮度：常亮模式恒 1，否则 = 距按钮距离在 250px 内的 smoothstep，以 `1 − e^(−8dt)` 渐变。

## 技术要求补充

- WebGL2（`#version 300 es`）、alpha 画布、`SRC_ALPHA / ONE_MINUS_SRC_ALPHA` 混合，每帧先清透明再画。
- 圆角上限为短边一半；字体加载后重算按钮尺寸。

## 完成后请检查

- 高光是边缘上的两段细亮线（对称），不是面上的光团
- 鼠标绕按钮转一圈，高光跟着沿边缘滑动；关闭常亮后靠近才亮
- 按钮本体透明、只有淡淡的暗描边
