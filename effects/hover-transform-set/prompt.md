## 效果描述

一排深色按钮，每颗悬停时整颗以不同方式动起来：持续一大一小地脉动；像被按下去一下再弹回；弹大一下再回来；放大并带明显的弹性过冲；微微转个角度；放大同时微转；往下沉一点；先浮起来然后在高处上下轻轻点头；先下沉然后在低处轻点；整体斜切；以左下角为轴向前倾；上下晃几下逐渐停住；剧烈抖动后停下。悬停时边框同时变成蓝色。强度、颜色、圆角都可调，也可以只显示其中一种。

## 实现提示

所有变体只改按钮自身的 `transform`（`transition: transform 0.3s ease`），幅度乘一个「强度」CSS 变量。脉动：关键帧 `25% scale(1.1)`、`75% scale(0.9)`，1s 线性无限；按下 / 弹起：`50% scale(0.8 / 1.2)`、`100% scale(1)` 播一次 0.3s；弹性放大：`scale(1.2)` 配 `cubic-bezier(0.47, 2.02, 0.31, -0.36)`、0.5s；微转 `rotate(4deg)`；放大微转两者相乘；下沉 `translateY(8px)`；浮起轻点用两段动画——先 0.3s 到 `translateY(−8px)` 并保持，再从 0.3s 起 `−8px ↔ −4px` 1.5s 交替无限；下沉轻点同理取正值；斜切 `skew(−10deg)`；前倾同样斜切但 `transform-origin: 0 100%`；上下晃：`8 / −6 / 4 / −2 / 1 / 0px` 六段衰减、1s；抖动停：`±3px` 配 `±2deg` 逐步衰减到 0 的十段、0.75s。
