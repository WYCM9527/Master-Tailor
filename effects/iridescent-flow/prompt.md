## 效果描述

给页面加一个「虹彩流光」的全屏背景：大块的虹彩色斑像油膜一样缓缓翻涌、互相渗染，整体罩着一层统一色调。开启鼠标跟随时，鼠标移动会让整幅画面朝指针方向轻轻偏移。色调、翻涌速度与偏移量见参数。

## 实现提示

- 用一张全屏 WebGL canvas，色斑完全由片元着色器数学合成，不要用图片或 CSS 渐变。
- 核心是「相位反馈循环」：两个标量 a、d 在循环里互相进入对方的三角函数（`a += cos(i - d - a*x); d += sin(y*i + a);` 迭代 8 轮），出来的相位场天然带流体等值线的形状。
- 相位翻译成颜色时分两步：先 `cos(uv * vec2(d,a))*0.6+0.4` 得到底层色斑，再整体过一遍 `cos(col * cos(vec3(d,a,2.5)))` 揉出虹彩渗染感，最后乘色调统一色相。
- 时间进入 d 的初值（负方向）并在循环后加回来，色斑才会「原地翻涌」而不是整体漂移。
- 鼠标只做很小的 uv 平移（默认 0.1），是氛围点缀不是交互主体。

## 技术要求补充

- WebGL1 + 全屏大三角形（3 顶点）即可，无需任何第三方库。
- uv 用短边归一（`uv * res / min(res.x, res.y)`），保证宽屏窄屏色斑比例一致。
- 页面切后台暂停时间累计；分辨率跟随 devicePixelRatio（上限 2 倍）。

## 完成后请检查

- 色斑边界柔和、颜色互相渗染，没有明显的重复平铺感
- 动画是缓慢翻涌，不是整幅图案朝一个方向平移
- 开启系统「减少动态效果」后定格为静态色斑
