## 效果描述

画面中央一个大字，周围一圈圆形小图沿着一条看不见的轨道匀速环绕——轨道默认是一个微微倾斜的扁椭圆，也可以换成圆、五角星、心形、无穷符号、波浪或三角。图片彼此等距、始终保持正立，绕一圈约 40 秒，可反向，可显示轨道线。图片、形状、半径、倾斜、时长、尺寸见参数。

## 实现提示

- 用 CSS Motion Path：每张图 `offset-path: path('…')`，`offset-rotate: 0deg`（不跟随切线旋转），`offset-anchor: center`，动画 `@keyframes { from { offset-distance: 0% } to { offset-distance: 100% } }` 线性无限循环；第 i 张（共 n 张）`animation-delay: −(i/n) × 时长`，就均匀撒在轨道上。反向用 `animation-direction: reverse`。
- 路径在一个固定的 1400×1400 设计稿坐标系里生成，再把整个设计稿按容器宽度 `scale()`，任何尺寸下比例一致。椭圆用两段 `A` 弧；星形按外内半径交替取点；心形与无穷符号用三次贝塞尔；波浪上下两条正弦折线闭合。
- 轨道整体 `rotate(倾斜角)`，每张图内部再 `rotate(−倾斜角)` 抵消，图片保持正立。
- 显示轨道线时在同一坐标系放一个 `<svg viewBox="0 0 1400 1400">` 画同一条 path。

## 技术要求补充

- 纯 CSS 动画，无 JS 逐帧；图片 `object-fit: cover` 圆形裁切，带柔影。
- 系统开启「减少动态效果」时动画暂停在初始分布。

## 完成后请检查

- 图片沿轨道匀速运行、彼此等距、始终正立
- 切换形状后轨道随之改变，显示轨道线时图片正好压在线上
- 缩放窗口时整体等比缩放不变形
