## 效果描述

列表页排着几张带标题的图片卡片。点开任意一张，那张图不是跳走，而是原地长大——连着圆角一起舒展成详情页顶部的大图，卡片上的小标题也一路放大挪到正文标题的位置，其余内容跟着淡入。按返回、Esc 或从左缘右滑，整个过程严格倒放，大图收回原来那张卡的位置。整体像同一件物体在两页之间移动，而不是换了一张页面。

## 技术要求补充

- 用同文档 View Transitions（document.startViewTransition）实现页面切换；view-transition-name 在同一时刻必须全文档唯一——只给「参与本次转场」的那张卡挂名，转场结束立刻移除，重名会让浏览器直接跳过转场
- 浏览器没有该 API 时降级为两页交叉淡化（CSS 类走同一套时长与曲线），功能照常；开启「减少动态效果」时一律瞬间切换
- 图片快照设置宽高 100% 加 object-fit: cover，宽高比变化时按裁切处理，不能拉伸变形
- 如果要在多页应用（两个独立 HTML）之间做同款转场：两页同源，各自声明 @view-transition { navigation: auto }，共享元素名一一对应（Chrome 126+ / Safari 18.2+ 支持，Firefox 暂不支持，需接受淡化降级）

## 实现提示

两个「页面」是同文档里互斥显示的两块区域（hidden 切换）。go() 前在 html 上写 data-vt="forward|back"，CSS 按方向选动画；startViewTransition 的回调里换页并把共享元素名挂到进场侧。::view-transition-group(hero/title) 设 animation-duration 与缓动承接位置尺寸补间；::view-transition-old/new(hero) 设宽高 100% + object-fit: cover。无 API 时两页短暂同框，播同一套 CSS 淡化动画，动画结束隐藏旧页。

## 完成后请检查

- 点开与返回是同一条路径的正放与倒放，大图的起点和终点都严丝合缝对准那张卡
- 转场进行中连续点击不会错乱（进行中的导航应被忽略）
- 不支持视图过渡的浏览器里切换依然可用，只是变成交叉淡化；开启「减少动态效果」后为瞬间切换
