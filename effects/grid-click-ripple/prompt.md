## 效果描述

背景是铺满整个页面的等大方格，格线很淡。鼠标悬停在哪一格，那一格会亮起来；点击任意位置，以点击的那一格为中心，亮色像水波一样一圈圈向外传开：近处的格子先亮、远处的格子晚一点亮，每个格子亮起后再慢慢淡回透明，于是看起来是一道亮环从点击处扩散到全屏、越远越淡。可以连续点出多道涟漪叠加。传播速度、波峰宽度、淡回时长、格子大小、颜色都可调。

## 实现提示

一个 `position: fixed; inset: 0` 的 CSS Grid 容器，按 `ceil(视口宽 / 格子) + 1` 列、同理行数生成足够的方格 div，每格用 `box-shadow: inset 0 0 0 0.5px 格线色` 画边。每格记下自己的列号行号。点击时对每个格子算到点击格的距离 d（格数），用 Web Animations API 播一段关键帧：透明 → 20% 处到达峰值亮色（强度随 d 递减）→ 透明，`delay = d / 速度 × 100ms`，时长 = 波峰宽度 × (100ms / 速度) + 淡回时长 × 0.3——delay 随距离线性增加就是「向外传播」；时长只比相邻圈的间隔长几倍，同时亮着的才是一道几格宽的环而不是一整片。悬停用 `:hover` 直接变色。

## 完成后请检查

- 涟漪中心在点击的格子上，向外传播、越远越淡；连点能叠加
- 格子铺满视口没有露边；悬停单格即时亮起
- 系统开启「减少动态效果」时点击不产生涟漪；没有鼠标时缩略图里自动随机点击
