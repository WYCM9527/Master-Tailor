## 效果描述

一排深色按钮，每颗悬停时底色以不同的方式换成蓝色：整块直接渐变；换色后底色还在一明一暗地脉动；一层蓝色从上往下扫满；从右往左扫满；从左扫入但冲过头再弹回；从正中一个圆扩散铺满；底色先是蓝的、一个深色圆从外向中心收走；一个矩形从中心长满；深色底从中间向上下合拢成一条线消失；蓝色从中间向左右展开。填充后文字换成深色。填充色、时长、圆角都可调，也可以只显示其中一种。

## 实现提示

按钮 `position: relative; overflow: hidden; isolation: isolate`，文字包在 `<span>` 里置于上层。所有填充变体共用一个 `::before`（`inset: 0`、填充色），只改初始 `transform` 与 `transform-origin`：向下扫满 `scaleY(0)` origin 顶部；向左扫满 `scaleX(0)` origin 右侧；回弹扫入 `scaleX(0)` origin 左侧、悬停时曲线换成 `cubic-bezier(0.52, 1.64, 0.37, 0.66)`；圆形扩散 `border-radius: 100%; scale(0) → scale(2)`；圆形收走反过来——按钮底色设为填充色、`::before` 用按钮原底色 `scale(2) → scale(0)`；矩形长满 `scale(0) → 1`；上下合拢同样反向——`::before` 为原底色 `scaleY(1) → scaleY(0)`（origin 中心）；左右展开 `scaleX(0) → 1`（origin 中心）。渐变换色与底色脉动不用 `::before`，直接过渡 `background-color`，脉动加一段 `50% { background-color: 混入 30% 底色 }` 的 1s 无限关键帧。悬停时文字颜色过渡到「填充后文字色」。
