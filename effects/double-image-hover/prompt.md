## 效果描述

一排竖版图片卡。悬停某一张，画面从右边开始被一道竖直的边「抹」向左边，抹掉的地方露出底下另一份同样的图——但它一开始是刺眼的偏色高亮（像过曝的蓝调底片）并且略放大，随着上层被抹掉，它同时回落成正常的颜色、缩回原大，最后整张卡看起来和原来一样却像被重新冲印了一遍。移开鼠标反向恢复。揭示方式可换成从中心收成一个圆、以右上角为圆心缩进角落、四块各自缩向外角、或切成六条百叶依次收薄。偏色、时长、圆角都可调。

## 实现提示

每张卡一个 `overflow: hidden` 的框，里面叠两份同图（`background-size: cover`）：底图 `transform: scale(1.15); filter: brightness(4) saturate(2) hue-rotate(偏色)`，顶图完整盖住。悬停时底图过渡到 `scale(1)` 与 `filter: none`；顶图用 `clip-path` 过渡：抹掉是 `polygon(0 0, 100% 0, 100% 100%, 0 100%) → polygon(0 0, 0 0, 0 100%, 0 100%)`，圆收缩 `circle(71%) → circle(0%)`，角落 `circle(141% at 100% 0) → circle(0% at 100% 0)`；四块变体把顶图复制四份分别裁成四个象限，各自过渡到自己外角的零面积多边形并错开 50ms；百叶变体复制六份用 `inset(顶 0 底 0)` 裁成横条，过渡到各自中线的零高 `inset`。过渡曲线 `cubic-bezier(0.7, 0, 0.3, 1)`。

- 五种揭示方式各自成立，四块与百叶有错开
- 系统开启「减少动态效果」时直接切换；没有鼠标时缩略图里轮流演示
