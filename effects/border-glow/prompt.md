## 效果描述

一张深色圆角卡片，平时只有一圈很淡的白边。鼠标移进来后，指向鼠标方向的那一段边框亮起紫粉蓝的网状渐变，同时向卡片外溢出一团暖色光晕、向卡片内透进一点柔光——越靠近边缘越亮，在卡片正中央几乎不亮；鼠标离开后光慢慢熄灭。没有鼠标时光会自己绕卡片扫一圈。颜色、圆角、光晕外扩、亮段宽度、起亮距离见参数。

## 实现提示

- 结构：卡片（`isolation: isolate`）里叠三层绝对铺满的装饰层 + 内容层。
- 网状渐变 = 7 个 `radial-gradient(at 位置, 色 0px, transparent 50%)` 色斑加一层底色，位置取 `80% 55% / 69% 34% / 8% 6% / 41% 38% / 86% 85% / 82% 18% / 51% 4%`，颜色按 `0,1,2,0,1,2,1` 从色表取。
- 层 1 边框：把网状渐变铺在 `border-box`、再叠一层卡片底色铺 `padding-box`，只有 1px 边框处露出渐变；`mask-image: conic-gradient(from 鼠标角 at center, black 亮段%, transparent 亮段+15%, transparent 100−亮段−15%, black 100−亮段%)` 只保留指向鼠标的一段。
- 层 2 填充：同一套渐变铺 `padding-box`，`mix-blend-mode: soft-light`，多重 mask（整块减去中央椭圆、加回四个角落小椭圆、再乘一个背向鼠标的锥形）只留靠边一圈，透明度是边框亮度的一半。
- 层 3 外光晕：容器 `inset: −外扩px`，内部同形状元素堆 13 层 `box-shadow`（6 层 inset + 6 层外 + 1 层内描边，模糊 1→50px、透明度 60%→10%）用光色 hsl 表达；容器 `mix-blend-mode: plus-lighter`，锥形 mask 只留鼠标方向 ±7.5%。
- 鼠标 → 方位角 `atan2(dy, dx) + 90°`；靠边程度 `1 / min(半宽/|dx|, 半高/|dy|)` 夹到 0–1。边框亮度 `(靠边×100 − (起亮+20)) / (100 − 起亮 − 20)`，光晕亮度用起亮值不加 20；离开时全部归 0。进入过渡 0.25s、离开 0.75s。
- 自动扫圈：亮度 0.5s 起、角度 110°→465° 先 easeIn 1.5s 再 easeOut 2.25s、末 1.5s 熄灭。

## 技术要求补充

- 纯 CSS 渐变 + mask + 混合模式，JS 只算角度与亮度写 CSS 变量。
- 系统开启「减少动态效果」时不自动扫圈、亮度直接切换。

## 完成后请检查

- 光只出现在指向鼠标的那一段边框，外溢光晕柔和、内部有淡淡透光
- 鼠标在卡片中央几乎不亮，越靠边越亮；离开慢慢熄灭
- 无鼠标时光自动绕一圈
